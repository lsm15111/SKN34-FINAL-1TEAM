# 일반 설명(믿집 자료 밖) 점검 (2026-11-20)

사용자 결정: "일반설명 그렇게 말한대로하고" — 믿집 자료가 없을 때 LLM 일반 상식으로 숫자 없는 설명을 '일반 설명(믿집 자료 밖)'으로 보여요.

## 1. 켠 범위

- LLM 모드에서 답 작성기까지 돌린 뒤에도 '확인하지 못했어요'만 남은 턴(카드 · 조각 답이 없음)만이에요. 무료 모드는 부르지 않아요.
- 관문이 고른 담당이 `trade`이고 공종이 도배 · 목공뿐인 질문이에요. 복합(multi) · 가이드 · 되묻기는 빼요.
- '무엇 · 어떻게' 질문(뜻 · 차이 · 종류 · 방법 · 순서 · 고르는 법 · 관리)만이에요. '~해도 될까요?' 같은 판단형은 빼요.
- 빼는 질문(코드 규칙 `agent/v3/general.py`): 숫자(금액 · 기간 · 때 · 수량 · 치수), 업체 · 브랜드 · 제품, 하자 · A/S · 보수 · 환불 · 계약 · 법률, 전기 · 가스 · 구조 · 방수 · 배관 · 석면, '우리 집 봐 주세요', 정책 표시(price · period · vendor_reco · brand_reco · defect_judgement · legal_case · safety · my_house).
- 답 모양: 묶음 표시 '일반 설명(믿집 자료 밖)' + 첫 문장 + 본문 또는 단계 + 확인할 곳 줄(주제별 확인할 곳, 없으면 '실측 때 업체에 물어보시면 정확해요.'). '확인하지 못했어요' 줄은 빼요.
- 출력 검사: 아라비아 숫자와 '하루 · 이틀 · 두 겹' 같은 숫자 말, 업체 추천 · 브랜드 · 하자 판정 · 법률 · 위험 작업 낱말이 든 문장을 빼요. 금지 표현 · 지시문 누출 검사도 지나요. 첫 문장이 빠지면 쓰지 않아요.
- 모델: `gpt-6-luna`(작은 모델 역할 `general`), 지시문 `prompts/general_v1.md`.

## 2. 평가 (g1, LLM 모드 · 프로젝트 없음 · 운영과 같은 DB 색인 + 의미 검색)

질문은 켜기 전에 적어 두었고, 결과를 보고 규칙을 고치지 않았어요.

- 비용: 63턴 $0.0132(작성기 · 일반 설명 호출 합계), 한 턴 평균 2.90초.
- 일반 설명이 나온 2턴
  - G06 '벽지에 생긴 작은 기포는 어떻게 해요?' → '풀이 마르면서 생긴 기포는 시간이 지나며 가라앉기도 해요.' · '계속 남거나 커지면 억지로 누르거나 자르지 말고 시공 업체에 확인해요.'
  - G07 '천장 도배는 벽이랑 뭐가 달라요?' → '천장은 위를 보고 작업해 벽보다 도배가 까다로울 수 있어요.' · '천장 상태에 따른 시공 방법은 실측 때 업체와 확인해요.'
- held-out에서 모름으로 남은 3개는 모두 판단형('~해도 될까요?' · '~않을까요?') 또는 제품 · 하자 질문이라 범위대로 일반 설명을 하지 않았어요.
- G16 '합판이랑 MDF는 뭐가 달라요?'는 관문이 공종을 못 찾아 되묻기로 갔어요(합판 · MDF가 목공 낱말에 없음).

## 3. 남은 것

- 판단형 질문('~해도 될까요?')까지 넓힐지는 사용자 결정이 필요해요. 하자 · 안전 판단과 겹치기 쉬워요.
- 목공 자재 낱말(합판 · MDF 등)을 관문 낱말에 더하면 G16 같은 질문이 일반 설명이나 작성기로 가요(이번 범위 밖).
