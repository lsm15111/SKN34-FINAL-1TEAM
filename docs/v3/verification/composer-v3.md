# 작성기 v3 · 이어 붙이기 · 채팅 스크롤 점검 (2026-11-20)

사용자 지적
- "답변 한 번 주고 '답변을 다듬는 중이에요'가 뜬 뒤 바뀌어서 번복되는 것 같아요."
- "다 자동 답변인 거 아니지? LLM으로 정보 알려 주는 것도 적절히 써야 해요."
- "AI 채팅 창은 아래로 내려가면 위쪽도 따라와야 해요. 지금은 위가 고정이라 채팅을 쓰면 내용을 보려고 스크롤해야 해요."

## 1. 원인

| 증상 | 원인(코드) |
| --- | --- |
| 답이 바뀌어 보임 | LLM 모드가 무료 답 전체를 `draft`로 먼저 그렸다가, 작성기 답이 오면 `done`으로 통째로 바꿨어요(`turn.py` · `AiPanel.tsx`) |
| 모든 답이 '자동 답변' | 답마다 `notice: "자동 답변"`을 붙였어요. LLM이 쓴 글인지 코드가 만든 글인지 화면에서 알 수 없었어요 |
| LLM을 덜 씀 | 계산만 있는 답(기간 · 비용 · 방문 · 업체)은 작성기를 아예 부르지 않았어요('작성기: 계산 답만') |
| 정해 둔 글이 사라질 수 있음 | 작성기 답이 `[계산 묶음, 작성기 묶음]`만 남겨서 가이드 시작 순서 · 정책 줄 · 사진 안내 같은 정해 둔 글이 빠졌어요 |
| 새 답이 아래에 숨음 | 대화 목록에 스크롤 처리가 없었어요. 390x760에서 세 번째 질문이 목록 위에서 691px(목록 높이 641)에 있었고 scrollTop은 0 그대로였어요 |
| 웹 옆 칸이 안 따라올 때 | 폰 층(?ai=1)으로 연 뒤 창을 넓히면 `.layer { inset: auto }`가 `top`을 지워 sticky가 풀렸어요 |

## 2. 바꾼 것

- 서버: 고정 몫(계산 결과 · 정해 둔 글)을 검사해 SSE `part`로 먼저 보내요(비어 있어도). 마지막 답은 그 묶음을 그대로 앞에 두고 AI 묶음 또는 무료 몫을 붙여요. 먼저 보낸 답은 짧은 답으로 접지 않아요.
- 작성기 v3: 고정 몫을 앞에 그대로 둬요. 계산만 있는 답도 불러요(카드 · 조각 근거가 하나도 없으면 안 불러요). 지시문에 '이미 보이는 글은 되풀이하지 말고 근거에 있는 구체적인 조건 · 방법만'을 넣었어요.
- 되풀이 걸러내기: 고정 몫 글에 IDF 무게 포함률 0.45 이상인 문장, 계산 값을 다시 쓴 비교 표 줄, 고정 몫 아래 '~에 따라 달라져요'만 쓴 문장을 빼요.
- 화면: 묶음마다 '믿집 계산' · 'AI 답변' · '믿집 안내'. part 아래 진행 줄 'AI가 믿집 자료로 답을 쓰고 있어요'. 새 질문을 목록 맨 위로 올리고, 위로 올려 읽으면 '최신 대화로' 단추.

## 3. 포함률 기준(COVER) 고른 것

c5(작성기 v3, 걸러내기 전) 고정 몫이 있는 턴의 AI 문장 44개를 고정 몫 글과 견줬어요.

| 포함률 | 문장 예 | 판단 |
| --- | --- | --- |
| 1.00 | 하자인지는 믿집이 판정하지 않아요. | 그대로 되풀이 |
| 0.56 | 예상 일정에는 기존 벽지를 뜯는 시간이 포함되지 않으며, 실측 뒤 업체가 정해요. | 말만 바꾼 되풀이 |
| 0.47 | 목공이 끝난 뒤 도배하며, 실제 일정은 공정표로 확인해요. | 되풀이 |
| 0.36 | 몰딩 교체를 포함한 목공을 마친 뒤 도배해요. | 조금 더함(남김) |
| 0.10 | 문짝 상태가 좋으면 필름 리폼으로 비용을 줄일 수도 있어요. | 새 정보 |

되풀이는 0.47 이상, 새 정보는 0.36 이하라서 0.45로 정했어요.

## 5. 화면 확인(미리보기 3031, 무료 모드)

- 390x760 폰 층: 질문 4개를 보내도 새 질문이 목록 맨 위 8px에 오고, 답이 온 뒤에도 그 자리예요. 위로 올리면 '최신 대화로'가 목록 오른쪽 아래(8px 안쪽)에 뜨고, 누르면 마지막 질문으로 돌아가요.
- 1280x760 웹 옆 칸: 새 질문이 칸 맨 위 8px, 페이지 scrollY는 0 그대로예요.
- 360x740: 가로 스크롤 없음, 보내기 44px · 입력 칸 47px.
- 앱 브라우저 미리보기는 화면에 그려지지 않는 탭이라 부드러운 스크롤이 움직이지 않았어요. 그래서 움직임 줄이기 경로(바로 이동)로 같은 코드를 확인했어요.
