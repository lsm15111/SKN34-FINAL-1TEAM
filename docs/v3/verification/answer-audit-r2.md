## 못 한 것
- f2b에는 흔적(받은 카드 · 검색 위 조각)이 없어서, f2b만 다른 답(C10 · C24 · C25 [없음])은 답의 출처 조각으로 원인을 찾았어요. 의미 검색 순위 자체는 다시 뽑지 않았어요(유료 임베딩).
- 맞물림(카드 근거 조각이 검색 위 8개에 있는지)은 r2c 흔적으로만 봤고, 카드마다 따로 재지는 않았어요. 표의 점수는 덤 전 열쇠 점수예요.
- 프로젝트 맥락 숫자는 시험 사실(FACTS)이라 공정표에 공정별 구간이 없어요. 운영에서 '도배 며칠'에 공정표 전체 기간과 도배 구간이 함께 나오는지는 확인하지 못했어요.
