# 몰딩 질문 개선 (#159)

일반 챗봇(ChatGPT)과 같은 질문 3개를 v3 상담에 넣어 비교하고 고친 기록. 무료 모드(`LLM_LIVE=false`), 2026-11-20.

## 문제

| 질문 | 고치기 전 | 원인 |
| --- | --- | --- |
| 몰딩이 뭐야? | 무몰딩 설명으로 답함(틀린 답) | 카드 찾기가 글자 두 개 묶음 비교라 "무몰딩이 뭐예요?" 열쇠가 0.78점으로 1등. 맞는 카드는 0.57점 |
| 몰딩 종류좀 알려주고 차이좀 알려줘 | "확인하지 못했어요" | "좀 · 알려주고 · 알려줘" 군말로 점수 0.29, 받는 기준(0.55) 미달. "몰딩 종류가 뭐가 있어요?"는 0.62로 통과 |
| 몰딩 추천좀해줄래 | "확인하지 못했어요" | 고르는 기준을 담은 카드 없음. 1등 후보가 업체 추천 카드(0.30) |

- 근거 자료(LX하우시스 시공 가이드)와 몰딩 카드는 이미 있었음. 질문 → 카드 연결에서 막힘
- 일반 챗봇과 다른 점: 비교표 없음, 상황을 되묻지 않음, 카드 1장 4문장까지만

## 해결

- 비교표 카드
  - 카드에 `compare`(머리줄 + 줄마다 근거 번호) 칸 추가 → 답에 `UiCard(kind="compare")`로 붙음
  - 칸 글도 카드 문장과 같은 규칙: 근거 조각 안의 내용만, 원 단위 금액 · 기간 숫자 없음(테스트로 검사)
  - 폰 너비에서 가로 스크롤이 생기지 않게 방식마다 '칸 이름 · 값'으로 쌓아 보임
- 상황별 추천 = 되묻기 + 다음 카드
  - 카드 되묻기에 `next`(고른 답 → 이어 보일 카드) 추가
  - "몰딩 추천" → 기준 카드 + "이번 공사는 어디까지 하세요?" 버튼 3개
  - 벽 · 천장까지 새로 → 마이너스 · 무몰딩 조건 카드 / 도배만 새로 → 틈 메우기 · 순서 카드 / 색만 바꾸기 → 페인트 · 필름 카드
  - 버튼 대신 글로 답해도("도배만 새로 할 거예요") 같은 카드로 감
  - 특정 제품 · 업체는 추천하지 않음(정책 그대로). 방식을 고르는 기준만
- 용어 질문: 몰딩 종류 카드에 "몰딩이 뭐예요?" 등 열쇠 3개 추가
- 본문 흐름: 정의 → 일반 · 마이너스 · 무몰딩 한 문장씩으로 고쳐 씀. 세 가지가 있다고 한 뒤 일반 몰딩만 설명하고 실크벽지로 넘어가던 문장은 비교표 칸에만 남김

## LLM 모드인데도 카드 글이 그대로 나온 이유

- `LLM_LIVE=true`라 앱은 LLM 모드. 그런데 "몰딩이 뭐야?"에서 LLM 호출 0회(`trace.prompts=[]`)
- 받은 카드 점수(0.78)가 `T_HIGH`(0.62) 이상이면 '카드 먼저' 원칙으로 LLM을 부르지 않음(`agent/v3/turn.py`의 `_llm`, ADR agent-06)
- 결과: 카드를 잘못 고르면 그 오류가, 카드 문장 흐름이 어색하면 그 어색함이 그대로 화면에 나감. LLM이 바로잡을 기회가 없음
- 점수가 높을수록 LLM을 안 부르는 구조라, 열쇠가 딱 맞는 흔한 질문일수록 카드 글 그대로 나감

## 고친 뒤

| 질문 | 답 |
| --- | --- |
| 몰딩이 뭐야? | 몰딩 종류 카드(일반 · 마이너스 · 무몰딩) + 비교표 |
| 몰딩 종류좀 알려주고 차이좀 알려줘 | 같은 카드 + 비교표 |
| 몰딩 추천좀해줄래 | 기준 2문장 + 공사 범위 되묻기 → 고른 상황의 카드 |

비교표(근거: LX하우시스 시공 가이드 K255 · K256 · K909 ~ K911)

| 방식 | 어떻게 해요 | 먼저 볼 것 | 비용 |
| --- | --- | --- | --- |
| 일반 몰딩 | 천장 · 벽 이음매를 몰딩으로 덮어 가려요 | 실크벽지 끝선을 깔끔하게 정리해 줘요 | 셋 중 가장 낮아요 |
| 마이너스 몰딩 | 천장 · 벽 사이 홈 안에 몰딩을 숨겨요 | 천장 덧방이 필요하고, 홈에 간접조명 · 액자 레일을 넣을 수 있어요 | 일반 몰딩의 두 배 이상이에요 |
| 무몰딩 | 몰딩 없이 벽 · 천장 경계를 매끈하게 마감해요 | 벽 평탄화가 필수라 석고보드 작업을 권해요 | 일반 몰딩보다 높아요 |

## 일반 챗봇과 비교해 지킨 것

- 모든 문장 · 표 칸에 근거 번호. 근거 없는 말("체리색은 올드해 보임" 등) 없음
- 일반 챗봇은 마이너스 몰딩을 "몰딩 대신 홈을 냄"으로 설명. 제조사 가이드는 "홈 안에 몰딩을 숨김"이라 v3 답이 맞음
- 금액은 계산 엔진만 만듦. 표의 비용 칸은 정도(낮음 · 높음 · 두 배 이상)만

## 남은 것

- 군말 떼기 · 긴 용어 카드가 이기는 문제의 일반 규칙은 #158에서 따로 다룸. 이번에는 몰딩 카드 열쇠만 더함
- 다른 카드도 같은 흐름 문제가 있음. 규칙으로만 세어도 419장 중 54장 후보(정의가 첫 문장에 없음 14 · 주제 튐 44). 카드를 하나씩 고치기보다 LLM이 카드를 근거로 새로 쓰는 쪽을 검토(ADR agent-06 변경, 팀 결정 필요)
- 화면은 실제 답 JSON을 AI 칸 컴포넌트에 넣은 미리보기로만 확인함. 로그인한 AI 칸에서 직접 물어본 것은 아님
- LLM 모드는 바꾸지 않음(카드 점수가 높으면 카드 글 그대로)
