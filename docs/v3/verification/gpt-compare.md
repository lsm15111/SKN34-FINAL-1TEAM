# ChatGPT와 믿집 AI 같은 질문 비교 (2026-11-19)

## 어떻게 쟀나요
- **질문:** `evaluation/v3/gpt_compare_questions.jsonl`의 6개예요. 처음 고객 · 자재 비교 · 비용 · 하자 · 공정 순서 · 사진 요청이에요.
- **ChatGPT:** 사용자 계정으로 로그인한 chatgpt.com 웹(기본 모델, Think 끔)에서 질문마다 새 대화로 물었어요.
  - 보낸 때부터 답 글이 처음 보인 때, 글이 4초 동안 바뀌지 않은 때까지를 앱 브라우저에서 쟀어요.
  - G1은 재는 스크립트가 붙지 않아 시간이 없어요.
- **믿집 무료 모드:** 개발 미리보기(API 8031, DB `mitjip_v3`)의 `/api/ai/turns`를 같은 브라우저에서 불러 응답이 끝날 때까지 쟀어요. 시연 고객 계정, 표준견적서 화면 문맥이에요.
- **믿집 LLM 모드:** `evaluation/v3/llm_speed.py`를 썼어요. 같은 6개, 유료(예상 $0.10 미만), 질문 임베딩 + 묶음 다시 쓰기예요.

## 시간

| 질문 | ChatGPT 첫 글자 | ChatGPT 끝 | 믿집 무료 | 믿집 LLM 모드 (한 턴 전체) |
| --- | --- | --- | --- | --- |
| G1 처음 고객 | (못 잼) | (못 잼) | 0.35초 | 5.3초(처음 부름, 색인 · 임베딩 준비 포함) · 0.7초 |
| G2 실크 · 합지 | 2.3초 | 20.9초 | 0.32~0.42초 | 9.1초 · 3.7초(LLM 다시 쓰기 1회) |
| G3 33평 비용 | 3.6초 | 9.6초 | 0.29~0.42초 | 0.7초 · 0.8초 |
| G4 하자 | 2.9초 | 12.6초 | 0.30~0.36초 | 1.0초 · 0.8초 |
| G5 몰딩 · 도배 순서 | 2.0초 | 11.6초 | 0.36~0.40초 | 0.8초 · 0.7초 |
| G6 곰팡이 사진 | 25.1초(그림 생성) | 31.2초 | 0.33~0.44초 | 4.7초 · 3.5초(LLM 다시 쓰기 1회) |

- LLM 모드의 두 숫자는 '지금 설정'과 '모두 luna'로 돌린 값이에요.
  - 지금 설정에서도 공종 담당(trade)은 이미 luna(`openai_light_roles=trade`)라서, 이 6개에서는 모델 차이가 아니라 **처음 부름과 그다음 부름의 차이**예요.
  - G2의 9.1초 → 3.7초는 대부분 처음 연결 비용으로 봐요(추정).
- 믿집 LLM 모드에서 다시 쓰기를 하지 않은 턴(0.6~1.0초)은 대부분 **질문 임베딩 0.6~1.0초**예요. 임베딩을 DB 읽기와 같이 돌리거나 같은 질문을 캐시하면 줄일 수 있어요(다음 일).
- 믿집 `/ai/turns`는 답을 다 만든 뒤에 보내요. 그래서 위 시간이 곧 첫 글자가 보이는 시간이에요. ChatGPT는 글자를 흘려 보내서 첫 글자가 2~4초, 끝이 10~21초예요.

## 판단
- **속도:** 무료 모드는 ChatGPT보다 첫 글자가 5~10배, 답 끝은 25~60배 빨라요. LLM 모드도 다시 쓰기가 없으면 1초 안이에요. 다시 쓰기가 있으면 3.5~9초인데, 블록 단위로 흘려 보내면 첫 문장은 1초 안에 보낼 수 있어요(무료 문장을 먼저 보내는 방식, 설계 8장).
- **형식:** ChatGPT가 보기 좋은 까닭은 표 · 소제목 · 이미지 묶음 · 끝의 고르는 질문 폼이에요. 우리는 표(2열) · 단계 블록 · 끝의 '조건 고르기' 단추 묶음을 더하면 돼요. 이미지는 자체 자료로만 해요.
- **정확성:** ChatGPT는 근거 없는 시세를 말하고 답마다 숫자가 달라요. 출처도 업체 블로그 하나였어요. 믿집의 '숫자는 계산 엔진만' 원칙은 그대로 두는 게 맞아요.
- **배울 것 하나:** ChatGPT도 첫 질문 뒤에 **방 개수**를 되물어요. 전체 도배 방안 4(방 개수 칸)와 방향이 같아요.
