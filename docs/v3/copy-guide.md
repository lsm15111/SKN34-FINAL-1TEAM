| 번호 | 정한 것 |

## 1. 용어 사전

- 코드 이름 칸: 그냥 적은 `이름`은 지금 코드에 있는 것, '(제안)'이 붙은 이름은 아직 없는 것이에요. 제안 이름은 개발자가 `data-model.md`에서 정해요.
- 같은 기능은 화면마다 같은 이름으로 불러요(WCAG 3.2.4 [R14]).
- 새 표 · 상태 이름은 개발자 ADR [dev-04](adr/dev-04-visit-scheduling.md)(실측 일정) · [dev-05](adr/dev-05-thread-storage.md)(채팅) · [dev-07](adr/dev-07-reviews-reports.md)(리뷰 · 신고)이 고른 것을 따랐어요(2026-11-18 확인).
