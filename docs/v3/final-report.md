### 마지막 점검에서 리드가 고친 것

- E2E-01(C12): '가견적 준비 중'인 가까운 구 업체 카드에도 구 이름이 보여요. `VendorCard`에 `place` 칸을 더했어요.
- C38 · D24: '3일 전에 한 번 알려 드려요' 대신 9판처럼 알림 날을 보여요('1.9(토)에 한 번 알려 드려요').
  - 날짜는 계산 엔진 `done_remind_at`을 API 칸으로 내보낸 값이에요.
  - 함께 고친 것: 백엔드 시험, 예시 데이터, e2e 기대값 3곳, `schema.d.ts`(새 칸 5줄만 달라짐)
  - 폰 390에서 '11.22(일)'과 '에'가 두 줄로 갈라져서, 날짜 + 조사를 한 덩어리로 묶었어요. 다른 화면에도 같은 줄바꿈이 있을 수 있어요. 공용 날짜 조각으로 한 번에 묶을지는 다음 일로 남겨요.
- 테스트가 AI router를 앱에 한 번 더 붙이던 것을 지웠어요(경고 4개).
- `.gitignore`에 `frontend/e2e/.out/`(시험 결과 · 스크린샷 22MB)를 더했어요.
- `tsconfig.json`: 역할별 빌드 폴더 줄을 지웠어요. `exclude`의 `.next-*`와 e2e 폴더 줄은 남겼어요(e2e를 돌릴 때마다 Next가 다시 더하지 않게요).
