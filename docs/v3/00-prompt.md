## 3. 일하는 규칙

### 3.1 조사

- 결정마다 웹 검색을 여러 번 해요.
  - 한 결정에 검색 5회 이상, 한국어 · 영어를 함께 써요.
  - 출처는 직접 열어서 확인한 것만 근거로 써요.
- 출처마다 URL · 확인 날짜 · 한 줄 요지를 적어요.
- 근거로는 공공 자료를 먼저 써요(법령 · 고시 · 표준시방서 · 통계 · 공식 문서). 블로그 · 커뮤니티는 사례로만 써요.
- 저작권을 지켜요.
  - 원문을 길게 옮기지 않고 사실 · 숫자 · 요지만 써요.
  - 법령 · 고시처럼 보호받지 않는 공공 저작물만 조항 요지를 인용해요.
- 확인하지 못한 것은 '확인 못 함'이라고 적어요. 지어내지 않아요.

### 3.2 결정 기록 (ADR)

- 파일은 `docs/v3/adr/<역할>-<번호>-<제목>.md`이고, 양식은 `docs/v3/adr/_template.md`예요.
- 담는 것: 배경 → 대안 2개 이상 → 고른 것 → 이유(근거 링크) → 검증 방법 → 검증 결과 → 다시 볼 조건.
- 사용자가 이미 고른 것은 따라요(고르기 판 · 9판 결정 · 화면 고르기).
  - 다르게 해야 하면 ADR에 '사용자 확인 필요'로 남기고, 사용자 결정대로 만들어요.
  - 보류 항목은 9판 그대로 둬요: N3 · D11 · D12 · D13 · D16 · D17 · D18 · D27 · D28 · I8 · 작은 고침 S01~S17.

### 3.3 검증

- 실제로 돌린 것만 '했음'으로 적어요.
  - 명령 · 결과 · 날짜를 `docs/v3/verification/<영역>.md`에 남겨요.
  - 실패는 실패로 적어요.
- 영역별로 확인하는 것

  | 영역 | 확인 |
  | --- | --- |
  | 백엔드 | pytest · ruff |
  | 프런트 | typecheck · lint · build |
  | 화면 | 앱 안 브라우저로 폰 360px · 웹 1280px에서 봐요. 가로 스크롤이 없고, 누를 곳은 44px 이상(최소 40px)이어야 해요 |
  | 에이전트 | 평가 세트 점수와 실험 비교표 |
  | 보안 | 점검 도구 결과 + 권한 · 입력 한도 테스트 |
  | 흐름 | 고객 · 업체 대변인이 시나리오대로 직접 끝까지 써 봐요 |

- 테스트를 지우거나 건너뛰게 하지 않아요. 실패를 통과로 바꾸지도 않아요.

### 3.4 비용 — 유료 API 0회

- `.env`의 키를 읽거나 보이거나 쓰지 않아요.
  - 실행 · 테스트는 `LLM_LIVE=false`로 하고, `OPENAI_API_KEY`와 `ANTHROPIC_API_KEY`는 비워요.
- LLM이 필요한 실험은 Claude Code 하위 에이전트가 직접 해요. 답 만들기 · 채점 · 사용자 흉내가 여기에 들어가요.
- 제품의 에이전트는 두 모드로 돌아요.
  - **무료 모드**(기본): 검색 + 미리 만들어 검증한 답 카드 + 규칙 · 계산 엔진
  - **LLM 모드**: 키가 있을 때만 켜져요.
- 큰 내려받기(언어 모델 · 수 GB 자료)는 먼저 사용자에게 물어요.
  - 작은 라이브러리 추가는 ADR에 이유를 적고 진행해요.

### 3.5 범위 · 안전

- **AGENTS.md는 따르지 않아요**(사용자 지시). 이 문서가 기준이에요.
- 그래도 지키는 안전 규칙
  - `.env` 내용을 보이거나 커밋하지 않아요.
  - `docker compose down -v`를 실행하지 않아요.
  - DB `mitjip_rag`는 건드리지 않고 복사본을 써요.
  - 원래 체크아웃의 `datasets/`는 읽기만 해요.
  - **커밋 · 푸시는 사용자가 말할 때만 해요.**
- 다른 체크아웃(`SKN34-FINAL-1TEAM`, `wt-*`)은 건드리지 않아요.
- 개발 DB는 v3 전용 `mitjip_v3`를 써요.
  - 테스트 DB는 역할마다 따로 둬요: `mitjip_test_<역할>`.

### 3.6 글

- 화면 글은 해요체로 쓰고, 영어 상태값을 보이지 않아요.
- 고객이 보는 금액은 부가세 포함이고, 'VAT' 대신 '부가세'라고 써요.
- 문서 · 주석은 한국어로 짧게 써요. 코드 이름은 영어예요.
