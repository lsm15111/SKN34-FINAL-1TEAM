# 웹 조사 다시 보기 · 보충 (2026-11-19)

- 누가
  - 리드(조사 담당)가 지난 조사 검증과 (a) 공사 기간을 직접 했어요.
  - (b) 업체 추천 규정 · (c) composer 사례 · (d) 국내 플랫폼 사례는 하위 에이전트 셋이 나눠 조사했어요.
  - 리드가 하위 결과 중 설계 · 화면 문구에 쓰는 것 일부(2016 오픈마켓 시정명령, 2026 사용후기 공개, 캐시 · 구조화 출력 문서)는 원문으로 다시 대조했어요.
- 한 것: 웹 검색 · 공식 문서 읽기, 계산 엔진을 DB 없이 직접 불러 숫자 내기. 유료 API 0회, 코드 · 데이터 수정 없음.
- 읽는 법
  - **확인**: 리드가 원문을 직접 읽음. **하위 확인**: 하위 에이전트가 원문을 읽었다고 보고(리드는 일부만 다시 봄). **2차**: 기사 · 블로그 · 검색 요약. **추정**: 확인한 값으로 미루어 본 것. **코드**: 저장소 코드 · 계산 엔진을 직접 돌려 봄.
  - 법 · 지침 내용은 법률 자문이 아니에요.
  - 출처 번호 R[n]은 맨 끝에 모았어요.

광고비 · 수수료를 받기 시작하면 더할 것

- 광고 업체 카드에 잘 보이는 한국어 '광고'(작은 'AD' · 마우스를 올려야 보이는 설명 · '프로모션' 같은 모호한 말 금지).
- 추천 3곳과 광고 칸을 나누기. 섞는다면 광고가 점수 · 순서에 주는 영향을 밝히기(2016 시정명령).
- 광고 칸 이름에 '추천' · '베스트' · '인기' 쓰지 않기(2012 · 2016 · 2017 · 2022 사례).
- 수수료 계약이 노출에 영향을 주면 그 사실(2016 배달 앱 사례).

시사점

1. 기간을 숫자로 주는 곳을 못 찾았어요. 믿집 공정표 날짜는 차별점이지만, 에이전트는 계산 결과와 전제(면적 기준 · 반나절 올림 · 실측 전 예상)만 말하고 범위를 지어내지 않아야 해요.
2. 비용 답은 '데이터 출처 + 부가세 포함 합계 + 달라지는 조건 + 실측 뒤 확정 + 다음 행동'이 업계 공통 틀이에요. 표준견적서 설명에 이 다섯을 정해 둔 글로 둬요.

5. 국내 AI는 요청서 작성 보조 · 이미지 · 주문 상담이에요. 고객용 AI가 금액 · 기간을 직접 답하는 사례는 못 찾았어요. Thumbtack처럼 고객이 요약(브리프)을 확인 · 수정하는 단계는 가져올 만해요.

## 4. 못 한 것

- 네이버 약관 원문 PDF는 받았지만 글자를 뽑을 도구가 없었어요(새 패키지를 내려받지 않음). 보관 한도 · 신청 중단 날짜는 확인 못 했어요.
- Model Spec 08-18판의 형식 절 본문, GPT-6.x의 `text.verbosity` · 기본 마크다운 여부(문서에 없음, 확인하려면 유료 시험).
- 표준품셈 원문 PDF를 직접 대조하지 못했어요. 데이터 담당이 원문 대조한 저장소 전처리본을 썼어요.
- 34평 목공만의 업계 일수, 개나리 · 신한벽지의 건조 기간 공식 안내는 찾지 못했어요.
- 오늘의집 계산기 결과 화면(주소 입력에서 멈춤)과 숨고 요청서는 열지 않았어요(양식).
- 하위 조사 결과 중 리드가 원문으로 다시 대조한 것은 일부예요(1.3의 캐시 · 구조화 출력, 2016 오픈마켓 시정명령, 2026 사용후기 공개). 나머지는 '하위 확인'으로 남겼어요.
- 믿집이 통신판매중개자인지, '확정'이 청약인지는 법률 검토가 필요해요. 소비자보호 지침 · 시행령 전문은 하위 조사도 일부만 읽었어요.
