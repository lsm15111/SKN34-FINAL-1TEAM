# 바닥 공종 에이전트 설계(2026-11-26)

설계 문서예요. 코드는 아직 없어요. 기본 정보는 v4 '우리 집 정보'(`feat-v4-secretary`) 기준이고, 에이전트 틀은 dev `agent/v3/specialists/` 기준이에요. 화면 작업은 뺐어요.

## 0. 한눈에

- **목표:** 바닥을 도배처럼 'deep' 공종으로 올려요. 기본 정보와 되묻기 답으로 계산 엔진이 금액 · 기간 · 순서를 내고, 에이전트는 근거 있는 설명만 해요.
- **받는 값은 세 층이에요.**
  1. 기본 정보: 폼에서 받고 보드에서 고쳐요. 금액 · 기간 · 순서를 바꾸는 칸이에요.
  2. 모은 조건: 되묻기 단추 답이에요. 답을 좁히거나 종류에 딸린 세부 칸이에요.
  3. 실측: 업체가 눈으로 보는 것이에요.
- **바닥 칸:** 기본 정보에는 공정 목록과 바닥 칸 2개(바닥재 종류 · 바닥 범위)를 더해요. 되묻기 칸은 6개예요. 나머지는 v4 기본 정보를 그대로 써요.
- **작업:** 12개(W1~W12, 6장)예요. `calc=True`는 계산 엔진(W4)이 끝난 뒤에 켜요. 지금은 `calc=False`라 관문이 바닥 금액 질문을 범위 밖으로 보내요(`gate.py:169`).
- **고를 것:** 7개(7장), 모두 추천을 붙였어요.

## 1. 전제(정한 것)

- 바닥도 금액 · 기간을 내요. 숫자는 계산 엔진만 만들어요(11-25 결정, AGENTS.md 3장).
- 신축 기준 · LHCS · 제조사 글은 '참고 기준'으로 말해요(11-25).
- 순서는 마루면 도배 전, 장판 · 데코타일이면 도배 뒤예요. 종류를 모르면 도배 뒤에 두고 안내해요(C, `calc/v2_plan.plan_order`).
- 철거는 공정이 아니라 조건이에요(v4 `16-trade-expansion.md` 2.4).
- 범위 밖: 난방 배관 · 온돌 다시 깔기(난방공사 등록 필요), 바닥충격음 기준 맞춤 보장(신축 주택 기준)이에요(같은 문서 2.2 · 6장).
- 에이전트는 DB에 쓰지 않아요. 고객이 누른 단추만 기능 service가 저장해요(AGENTS.md 4장, `trades.Slot`).

### 2.3 칸끼리 이어지는 규칙(service · 계산 엔진 몫)

- 철거 범위가 전체면 걷어내기를 '걷어냄'으로 두고 덧방은 묻지 않아요.
- 철거 범위가 '안 함'이면 덧방이 전제예요. 기존 바닥을 묻고, 덧방할 수 있는지는 '실측 후'예요.
- 기존 바닥이 모름이면 걷어내기 줄은 '실측 후'예요.
- 종류가 모름이면 공정표는 도배 뒤에 두고 안내해요(구현됨). 금액은 7장 3번에서 정해요.
- 마루 세부 · 장판 두께가 모름이면 자재 줄은 종류의 범위로 둬요(D에서 범위 근거).
- 발코니 확장이 아니면 발코니 칩을 빼요.
- 살면서 공사면 방을 나눠 비우는 준비가 붙어요. 기간을 늘리는 규칙은 E에서 정해요.

### 3.3 칸을 어디서 받을지 정하는 원칙

1. 금액 · 기간 · 순서를 바꾸는 칸은 기본 정보에 둬요. 보드에서 고칠 수 있어요(`floor.kind` · `floor.spaces`).
2. 답을 좁히거나 종류에 딸린 세부 칸은 되묻기로 받아 모은 조건에 둬요.
3. 눈으로 봐야 하는 것은 실측(`survey`)이에요. 수평 · 습기 · 갈라짐 · 배관 · 문 간섭이 여기 들어가요.
4. 한 턴에 하나만 묻고, 아는 칸은 다시 묻지 않아요(`answer.slot_known` + 모은 조건).

- **기본 정보 칸:** `HomeInfoIn`에 더해요. `trade: Literal["dobae"]`는 `trades` 목록으로 바꾸고, 바닥 묶음은 `floor: FloorInfoIn | None`으로 둬요. 저장은 같은 PATCH(`/projects/{id}`)라 v4 보드 고치기 흐름이 그대로 돌아요.
- **되묻기 칸:** v4 모은 조건(`project_conditions`)에 둬요.
  - 키 `floor.<칸>`, 값은 단추 값만 받고 DB CHECK로 막아요.
  - dev에는 이 표가 없어 v4 migration(0038 표 · 0043 철거 · 0046 직접 할 일 · 0060 앞 공사)을 옮겨 와야 해요.
- **에이전트에 넘기기:** `ProjectFacts`에 더해요.
  - 더할 칸: `rooms` · `demolition` · `diy` · `built_year` · `balcony_ext` · `floor`(FloorFacts) · `brief`(모은 조건)

## 4. 에이전트 구조

### 4.1 한 턴

```
POST /ai/turns → chat.service(프로젝트 사실 + 모은 조건, 짧은 세션)
  → gate(바닥 낱말 → trade/floor, 금액 · 기간 말은 calc=True일 때만 통과)
  → turn → trade_agent → specialists/floor/agent.run
       1. 범위 밖: 난방 배관 · 온돌 · 폴리싱 · 석면 → 정해 둔 안내 + 다음 걸음(코드)
       2. 경계: 걸레받이 · 문 · 현관 타일 · 가구 → 담당 공종 한 줄 + 바닥 몫(코드)
       3. 순서: ORDER_RULES + plan_order(floor.kind) 문장(코드)
       4. 금액 · 기간: facts.standard 바닥 줄 · facts.plan 바닥 블록 → 계산 상자(값을 만들지 않음)
          값이 없으면 빈 칸 하나 되묻기, 칸이 다 차 있으면 '표준견적서 보기' 다음 걸음
       5. 지식: retrieval(묶기 표로 검색어 보강) → 카드 · 조각 문장
       6. 되묻기: 답을 바꾸는 빈 칸 하나(slot_known)
  → (LLM 모드) prompt_v1 지침으로 일부 다시 쓰기 → 검사(숫자 · 근거)
  → 저장 · commit → token · card · done
```

### 4.2 `specialists/floor/` 폴더

| 파일 | 내용 |
| --- | --- |
| `spec.py` | `TradeSpec("floor", "바닥", "deep", …)`. 낱말에 데코타일 · PVC 타일 · 헤링본 · 장판 두께 말을 더하고, 주의 문장은 C 문장이에요. `survey`(바닥 수평 · 들뜸, 기존 바닥 종류, 습기, 문턱 · 걸레받이 높이), `prep`(짐 옮기기, 살면서면 방 나눠 비우기), `slots`(3.2 되묻기 칸, `fact`로 기본 정보와 연결), `calc`(W4 뒤 True), `route_priority`(바닥 타일 ↔ 타일), `check_where`('실측 때 바닥 업체') |

| `prompt_v1.md` | 아래 지침 |

`prompt_v1.md` 지침:
- 신축 기준 · LH 시방서 · 제조사 글은 '참고 기준'이라고 밝혀요. 지금 집에 꼭 맞는 기준처럼 말하지 않아요.
- 금액 · 기간 · 수량 숫자는 계산 상자에 있는 것만 써요.
- 들뜸 · 단차 · 소리는 보이는 상태로 설명하고 원인을 단정하지 않아요.
- 난방 배관을 건드리는 일은 바닥 업체 몫이 아니라고 말해요.
- 층간소음은 바닥재로 기준을 맞춘다고 약속하지 않아요.

### 5.1 근거 자료

- **줄 꼴:** 모든 글이 같은 다섯 줄이에요.
  1. 바닥재(평 단가 × 평)
  2. 보양(대부분 '서비스')
  3. 인건비(품 × 단가)
  4. 식대(품 × 15,000원)
  5. 운송비(30,000원 1대)
  - 소계는 고른 줄 합과 233/233글이 같아요.
- **고른 자재:** 강마루 157 · 장판 70 · 초광폭 강마루 2 · 원목마루 2. 강화마루 · 데코타일은 0이에요.
- **바닥재 평 단가 중앙:** 강마루 120,000원(p25 ~ p75 120,000 ~ 140,000)이에요. 장판은 두께별로 2.2T 65,000 · 2.7~3.2T 95,000 · 4.5~5T 125,000원이에요.
- **수량:** 제목 평형(공급)의 0.90배(강마루) · 0.875배(장판)예요. 강마루는 R² 0.93, 장판은 0.97이에요.
- **인건비:** 품 단가 중앙 300,000원이에요. 품은 평 × 0.048로 작고, 1품 124글 · 2품 97글이에요. 소계 중 바닥재 줄이 88%(강마루) · 84%(장판)예요.
- **평 단가에 시공이 들었다고 봐요(추정).**
  - 인건비 줄은 1~2품뿐이에요.
  - 자재표의 마루 자재가만 평당 중앙 104,298원이고, 공공 마루 시공(표준시장단가 12,408원/㎡)이 평당 41,018원이에요.
  - 둘을 더하면 145,316원이라 시장 평 단가 120,000원보다 커요.
  - 그래서 평 단가 = 자재 + 시공, 인건비 줄 = 보조 일손으로 읽어요. 업체에 확인하면 좋아요.
- **바닥에 없는 것:**
  - 걸레받이는 목공(1300, 개 단위)에 있어요.
