# 07. 자재 · 질감을 고르면 "이렇게 시공돼요"

고객이 자재 · 질감을 직접 고르거나 말로 표현하면, 그 선택이 **어떤 공법 · 단계 · 기간 · 비용 등급 · 다른 공정 · 하자 위험**으로 이어지는지 보여 준다. 근거: [T5](../research/T5_material_method.md), [T2 도배](../research/T2_dobae.md), [T3 목공](../research/T3_mokgong.md).

## 1. 무엇을 보여 주나

고객이 '실크 · 회벽 질감 · 크림'을 고르면 화면에 **시공 카드**가 뜬다. 카드의 사실은 계산 엔진 · 정형 지식에서, 문장은 서브에이전트가 쓴다.

```
실크 · 회벽 · 크림을 고르셨어요
이렇게 시공돼요
 1. 기존 벽지 철거 (실크는 덧방이 안 돼요)
 2. 퍼티로 벽 고르기 → 2일 말리기
 3. 부직포 띄움 초배 + 이음 자리에 운용지
 4. 맞댐 시공 (이음이 거의 안 보여요)
 5. 마르는 3~4일 동안 들뜬 곳을 누르지 않기
바뀌는 것
 · 기간: 합지보다 철거 · 퍼티 · 초배 단계가 늘어요
 · 금액: 예상 범위 ⟦scenario.silk.low⟧~⟦scenario.silk.high⟧ (합지면 ⟦scenario.hapji.low⟧~⟦scenario.hapji.high⟧)
 · 다른 공정: 몰딩이 있는 게 좋아요(맞댐 시공 경계) · 간접조명 아래면 띄움 시공 필수
업체에 물어볼 것
 · 품번과 등급을 견적서에 적어 주세요 · 반입 롤 라벨 사진을 받아도 될까요?
```

- 단계 · 대기 시간 · 공정 관계는 `refprice/options.py`(레시피)에서, 금액은 **선택 시나리오**로 계산 엔진이 낸다(06 문서 1절 ① 고객 선택).
- 견적 범위 밖으로 끌려가는 공정(전기 · 필름 · 벽체 목공)은 **안내만** 하고 금액을 내지 않는다("간접조명은 전기 공사가 함께 들어가요. 믿집 견적에는 아직 없어요").

## 2. 선택 단위: 4축으로 정규화

T5 결론: 옵션 = **자재 등급 × 질감 × 색 · 패턴 × 레시피**. 고객은 앞의 셋을 고르고, 레시피는 현장 조건(기존 벽지가 합지인지, 구축인지)에 따라 엔진이 붙인다.

| 축 | 도배 | 목공 |
| --- | --- | --- |
| 등급 · 종류 | 합지 소폭 · 광폭, 실크, 프리미엄 실크, 친환경 실크, 패브릭 · 수입, 뮤럴, 기능성 | 몰딩(유지 · 평 · 계단 · 마이너스 · 무몰딩), 걸레받이(MDF · PVC · 마이너스 · 없음), 방문(문짝만 · 문틀 세트 · 필름 · 히든), 문선(일반 · 슬림 · 없음), 천장(유지 · 평탄화 · 등박스 철거 · 간접조명) |
| 질감 | 무지 · 페인팅 · 회벽 · 석재 · 패브릭 · 콘크리트 · 펄 | 마감(필름 · 도장 · 래핑) |
| 색 · 패턴 | 무늬 맞춤(없음 · 랜덤 · 스트레이트 · 하프드롭) → 롤 수 | 화이트 / 그 밖(주문 제작 · 리드타임) |
| 레시피(자동) | 덧방(합지 위 합지) · 실크 표준 · 수입 · 뮤럴 | 교체 · 리폼 · 평탄화 동반 |

## 3. 선택이 바꾸는 것 — 규칙 예 (T5 R01~R31에서)

| 바꿈 | 견적 | 일정 | 다른 공정 · 주의 |
| --- | --- | --- | --- |
| 합지 → 실크 | 자재 등급 ↑, **철거 · 퍼티 · 부직포 초배 · 운용지** 줄 추가, 롤 수 다시 계산 | 철거 · 퍼티 추가, 퍼티 뒤 2일 | 몰딩 상태 점검, 간접조명 아래면 띄움 필수 |
| 실크 → 합지 | 자재 ↓. 기존이 합지면 덧방으로 철거 · 퍼티 · 초배 생략 가능(기존이 실크면 철거 필수) | 짧아짐 | 겹친 줄이 보임(광폭 약 90cm, 소폭 약 50cm), 물걸레 불가 |
| 무지 → 패턴 | 무늬 로스로 롤 수 ↑(팀 기준 1개 + 범위: 1~2롤 / 5% / 10~15% 상충) | 맞춤 작업 ↑ | 같은 LOT로 발주 |
| 국산 → 수입 · 패브릭 | 롤당 면적 약 16.5㎡ → 약 5㎡, 롤 수 약 3배 | 수입 리드타임 | 전문 시공자, 풀 방식이 다를 수 있음 |
| 평몰딩 → 무몰딩 | 몰딩 철거 + 평탄화(석고 덧방) 줄 추가 | 목공 +1일 이상, 퍼티 +2일 | 도배 경계 마감 정밀, **구축 콘크리트 벽은 위험 큼** |
| 평몰딩 → 마이너스 | 일반 몰딩의 2배 이상(업계), 천장 덧방 | 목공 ↑ | 매입 조명 · 커튼레일은 전기 1차와 함께 |
| 걸레받이 → 마이너스 · 없음 | 벽체 목공 추가 → **1차 견적 범위 밖 플래그** | 목공 ↑, 바닥 · 도배 순서 조정 | 모서리 파손 |
| 문짝만 → 문틀 세트 | 문틀 철거 · 폐문 처리 줄 추가 | 약 2일, **도배 전** | 문선 주변 도배 재단 |
| 우물천장 유지 → 평탄화 | 평탄화 면적 줄 | 목수 2명 하루(업계 사례) | 노후 석고 탈락 시 천장 전체 보수, 스프링클러 · 감지기, **띄움 도배**, 2009년 이전 착공이면 천장재 석면 확인 권장 |
| 마루 ↔ 장판 | — | **도배 위치가 바뀜**: 마루는 도배 전, 장판은 도배 후 | 걸레받이는 바닥 뒤 |

- 금액 변화는 엔진이 시나리오 두 개를 계산해 나란히 보여 준다. 에이전트는 "왜 달라지는지"만 쓴다.
- 출처끼리 다른 값은 범위로 두고 팀 기준값 1개를 정해, 설명할 때 "자료마다 ○~○로 달라요. 믿집은 ○로 잡았어요"라고 말한다.

## 4. 말로 표현할 때 — 표현 사전

"호텔 같은 느낌", "몰딩 없는 깔끔한 천장", "우드 느낌 걸레받이" 같은 말은 **옵션 후보 + 되물을 것 + 연계 공정 플래그** 셋으로 바꾼다(T5 6장 60개).

| 표현 | 옵션 후보 | 되물을 것 | 플래그 |
| --- | --- | --- | --- |
| 하얀 무지 실크 / 그냥 흰 벽 | `WP_SILK_STD` + `TX_PLAIN` + 화이트 | 기존 벽에 금 · 요철이 많나요? | 무지는 바탕 결점이 드러남 → 퍼티 범위 ↑ |
| 호텔 같은 느낌 | `CP_MOLD_NONE`/`MINUS` + `CEIL_INDIRECT_*` + 슬림 문선 + 웜그레이 회벽 | 몰딩 철거 공사까지 원하세요, 벽지 · 색만으로 연출할까요? | needs_carpentry · needs_elec(범위 밖) |
| 몰딩 없는 깔끔한 천장 | `CP_MOLD_NONE` | 구축(콘크리트 벽)인가요? | 평탄화 · 퍼티 +2일 |
| 천장이 높아 보이게 | `CEIL_FLATTEN` / 마이너스 · 무몰딩 + 천장 화이트 | 우물천장이 있나요? | — |
| 가성비 · 빨리 | `WP_HAPJI_WIDE`(덧방 가능 여부) + 몰딩 유지 | 지금 벽지가 합지인가요? | 기간 · 비용 ↓ |
| 새집 냄새 싫어요 | HB 최우수 풀 · 접착제 + 환경표지 벽지 | — | 단가 ↑ |

- 처리 순서: ① 사전 조회(도구 `match_expression`) → ② 후보가 여럿이거나 `confidence < 0.6`이거나 범위 밖 공정이 끌려오면 **반드시 되묻기** → ③ 고객이 고른 옵션 코드만 계산 엔진에 넘김. LLM이 옵션을 확정하지 않는다.

## 5. 누가 맡나

| 상황 | 맡는 곳 |
| --- | --- |
| 화면에서 옵션 칩을 누름 | 코드가 시공 카드(레시피 단계 · 규칙 · 시나리오 범위)를 바로 그림. 설명 문장은 해당 공정 서브에이전트(버튼 호출, 관문 생략) |
| "실크랑 합지 차이가 뭐예요?" | 도배 서브에이전트 |
| "호텔 같은 느낌으로 하고 싶어요" (공정 둘 이상) | 오케스트레이터 → 목공 · 도배 서브 병렬 + 표현 사전. 전기 등 범위 밖은 안내 문장 |
| MVP 이후 | 자재 전담 에이전트(여섯 번째 후보, 02 문서 8절) — 공정을 가로지르는 스타일 상담 · 비교표가 많아지면 |

## 6. 미리보기 (시각화)

| 방식 | 판단 |
| --- | --- |
| A. 샘플 방 사진 + 미리 만든 레이어(벽 · 천장 · 몰딩 · 걸레받이 · 문 · 문선) + 텍스처 교체 | **MVP 권장(3~5일)**. 결정론, 저작권 통제, 몰딩 · 문선 옵션도 레이어 켜기 · 끄기로 보임 |
| B. 내 방 사진 + 클릭 세그멘테이션(SAM 계열) | 데모 수준만. SAM 3 라이선스(Meta 자체 라이선스) 상업 이용 조건 확인 필요 |
| C. 생성형 인페인팅 | 견적 오해 위험 → '분위기 예시' 표시가 있을 때만 |
| D. AR | 범위 밖 |

- 모든 미리보기에 "참고 이미지예요. 실제 색 · 질감은 샘플북으로 확인해 주세요"를 붙인다(제조사도 같은 고지를 한다).
- 제조사 제품 이미지는 약관 확인 전에는 쓰지 않는다. 절차적 텍스처(노이즈로 엠보 · 패브릭 느낌)나 CC0 텍스처를 쓴다.
