# v4 요청 점검(2026-11-23)

- 까닭: 사용자 "사용자 요청에 최대한 맞춰야" · 부족한 점 가운데 '요청을 다 했는지 스스로 점검'부터("그렇게해").
  - 실제로 놓친 부탁: 업체 5곳 부탁 → 1곳, "가격도 조사해봐" → 제품 정보만, "우리 집 정보 변경할게" → 카드 없이 글만.
- 방식: 고객 말에서 분명한 부탁만 코드가 뽑아요(`assistant/asks.py`, LLM 없음). 잘못 잡으면 LLM을 한 번 더 부르니 놓치는 쪽이 낫게 좁게 잡아요.

## 뽑는 것
| 부탁 | 예 | 잡는 조건 |
| --- | --- | --- |
| 수(2~10) | '업체 5곳 찾아줘' · '자재 3가지 더 조사해줘' · '조사해줘봐 5개까지' | 수 뒤(같은 문장)에 부탁 말(찾 · 알려 · 추천 · 골라 · 조사 · 비교 …), 또는 부탁 말 뒤의 수에 '까지 · 만 · 정도'. '방 3개인데' · '3개월'은 아님 |
| 값 | '얼마 나와?' · '판매가랑 규격 찾아줘' · '견적이랑 많이 차이나?' | 가격 · 얼마 · 판매가 · 값 · 시세 · 단가 · 차이 나. '얼마나 걸려' · '값싼' · '가격 말고' · '값이 들어가 있어요?'는 아님 |
| 보일 카드 | '우리 집 정보 변경할게' · '16평으로 바꿔줘' · '표준견적서 보여줘' · '업체 추천해 주세요' | 카드 이름 뒤 12자 안에 보기 말(보여 · 볼래 · 보기 · 열어 …). 집 정보는 바꾸기 말도. 사이에 '말고 · 빼고 · 방법 · 어떻게 · 계산 · 왜'가 있으면 아님. 종류는 show_card로 보일 수 있는 여섯(집 정보 · 표준견적서 · 공정표 · 견적서 비교 · 업체 추천 · 오늘 할 일) |

## 쓰는 곳
1. 턴 시작: 턴 사실 끝에 '이번 부탁(고객 말에서 코드가 뽑음): 5곳 · 값(가격) · 집 정보 카드. …' 한 줄(`runtime._Turn._messages`).
2. 조사 맡기기: 모델이 목표에서 뺀 찾을 수 · 판매가를 고객 말에서 붙여요('… · 5곳' · '… · 판매가', `start_research` → `asks.research_goal`). 제목에서는 뗘요. 자재 조사에서 값을 물었으면 조사 담당 첫 글에 '판매가' 줄을 더해요.
3. 턴 끝: 모델이 도구 없이 답을 마쳤는데 보여 달라 · 바꾸겠다고 한 카드를 이 턴에 보이지도 · 만들지도 · 부르지도 않았으면, 상한 안에서 한 번만 점검 글(모델에만 감)을 붙여 다시 불러요(`runtime._Turn._recheck`). 그 카드 도구를 불렀으면(받은 견적서가 없어 카드가 없어도) 다시 부르지 않아요.
4. 조사 끝 줄: 부탁한 수보다 덜 찾았으면 '부탁하신 5곳 중 3곳을 찾았어요.', 자재 조사에서 값을 물었는데 확인한 판매가가 하나도 없으면 '판매가는 판매처 페이지에서 확인하지 못했어요.'(`research.short_line`).
5. 기록: 부탁이 있던 턴만 `assistant_turns.trace.asks = {want, unmet, retry}`(글 없음).

## 하지 않는 것
- 업체 비서 · 카드 단추가 만든 말 · 인사 턴은 보지 않아요. 무료 모드도 보지 않아요.
- 말의 뜻을 LLM으로 다시 보는 점검(턴마다 비용)은 아직이에요. 코드 점검 기록(trace.asks)을 보고 정해요.
- 실측 시간 카드처럼 show_card로 못 보이는 카드는 점검하지 않아요.
