# v4 판정기 골든셋 샘플(사람 확인 35개)

Judge(Opus 5.5 한 답 판정기, `evaluation/v4/grade.py` · `rubric_single.md`)가 매긴 점수를 사람 판정과 견줘 **합격 커트라인**을 정하려는 표본이에요.

## 채우는 법

1. 항목마다 `내 판정: [ ] 합격 / [ ] 불합격` 중 하나를 `[x]`로 바꿔요(O = 합격, X = 불합격).
2. 기준은 "이 대화 · 답을 실제 고객에게 그대로 보여 줘도 되나?"예요. 아래 중 하나라도 있으면 불합격을 추천해요.
   - 틀린 사실 · 지어낸 숫자(계산 엔진 값이 아닌 금액 · 기간 · 날짜)
   - 하지 않은 일을 했다고 말함 · 승인 없이 진행
   - 물은 것에 답하지 않음 · 다음 걸음이 막힘
   - 범위 밖 공정의 금액 · 기간을 말함
3. Judge 점수에 끌리지 않게 **요약을 먼저 읽고 판정한 뒤** Judge 줄을 봐요.
4. 애매하면 메모에 까닭을 적어요. 커트라인 계산은 O/X만 써요.
5. 요약에 없는 턴이 궁금하면 `기록` 칸의 tag · key로 `evaluation/v4/runs/`에서 전체를 볼 수 있어요.

## 다 채운 뒤: 커트라인 계산

"골든셋 채웠어"라고 말해 주세요. 아래처럼 계산해 드려요.

- **후보 커트라인:** t = 5, 6, 7, 8, 9마다 "Judge 점수 ≥ t면 합격"으로 놓고 사람 판정과 견줘요.
- **셀 값:**
  - 일치율과 Cohen κ(우연히 맞는 몫을 뺀 일치도)
  - 거짓 합격: Judge는 합격인데 사람은 불합격(고객에게 나쁜 답이 나가요)
  - 거짓 불합격: Judge는 불합격인데 사람은 합격
- **추천:** κ가 가장 높은 t를 골라요. κ 차이가 0.05 안이면 거짓 합격이 적은 높은 t를 골라요.
- **함께 볼 것:** 지금 규칙의 "1~2점 항목이 있으면 불합격"이 일치를 높이는지, 시뮬레이터와 답에서 커트라인이 다른지도 봐요.
- **한계:** 35개라 구간이 넓어요. 추천값과 함께 부트스트랩 95% 구간을 드려요. 사람 불합격이 5개보다 적으면 경계 항목을 더 뽑아요.
- **기록:** 결과는 `docs/v4/eval/results.md`에 '사람 확인' 줄로 남겨요(지금은 사람 확인이 비어 있어요).
