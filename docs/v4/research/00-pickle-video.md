## 영상이 말한 것(자막 기준)
- 피클은 지난주 한국 앱스토어 무료 순위 2위까지 올랐어요. 뮤즈(Meta)는 22일 만에 500만 명이 내려받았어요.
- 챗봇은 틀리면 화면에 틀린 답이 뜨고 끝나요. 에이전트는 틀리면 틀린 행동(게시 · 전화 · 결제)이 밖으로 나가요. 그래서 모델보다 구조를 바꾸는 게 훨씬 비싸요.

### 결정 1. 셀(고객마다 칸)
- 고객 데이터를 큰 DB 한 곳에 섞지 않고, 고객마다 자기 칸(셀)을 줘요.
- 조건 하나를 빼먹으면 남의 데이터가 섞여 나오고, 에이전트는 남의 기억으로 남의 계정에 행동해요.
- 얻는 것: 무거운 고객 하나가 다른 고객을 느리게 하지 않고, 장애도 그 칸에서 끝나요.
- 잃는 것: 전체 조회와 통계가 어려워져요.

### 결정 2. 금고(비밀은 에이전트 밖)
- 에이전트는 비밀번호 · 카드 번호 · 토큰을 끝까지 못 봐요. 웹페이지에 숨은 문장 하나로 비밀이 밖으로 나갈 수 있어요.
- 흔한 실수: 에이전트 환경 변수에 토큰을 넣는 것, 사용자가 문자로 보낸 비밀번호를 그대로 넘기는 것.
- 문자에 섞여 온 카드 번호 · 비밀번호는 저장 전에 가리고 에이전트에는 넘기지 않아요.
- 에이전트는 요청만 보내고, 로그인 정보는 다른 곳이 붙여요.

### 결정 3. 게시는 코드가
- 되돌릴 수 없는 행동(게시 · 전화 · 결제)은 AI 판단으로 하지 않아요. 사람이 정해진 말로 승인했을 때만 코드가 실행해요.
- 사례: 피클이 2026-10-29에 사용자가 시키지 않은 전화를 걸었고, 대표가 사과한 뒤 업체에 전화하기 전 반드시 승인을 받게 바꿨어요.
- 코드로 정해 둘 것: 승인 요청이 여러 개 열려 있을 때 어느 것인지, 만료 뒤에 온 승인, 번호를 바꾼 지 얼마 안 된 사람의 승인.

### 결정 4. 기억은 사용자 말로만
- 웹페이지나 댓글을 읽은 작업에서는 기억을 바꿀 수 없게 잠가요. 안 막으면 남이 쓴 글 한 줄이 에이전트 성격을 바꿔요.
- 모든 기억 변경에 근거가 된 사용자 메시지 번호를 붙이고, 근거 없는 기억은 저장하지 않아요.
- 기억의 양을 정해 둬요. 끝없이 쌓으면 지시문이 길어지고 옛 선호가 새 선호를 이겨요.

### 결정 5. 잠과 상한
- 일이 없으면 잠들고, 잠든 동안은 돈이 안 나가요.
- 비용은 코드로 세 단계 상한을 걸어요(작업 하나 · 고객 한 명 · 서비스 전체). 예: 서비스 전체 상한 200달러, 넘으면 "지금 요청이 많다"고만 답해요.

### 다섯 개 다음에 터지는 것(실사용 첫 주)
1. 메시지 순서가 뒤집힘
2. 같은 메시지가 두 번 들어옴(멱등성)
3. 일이 조용히 멈춤(오류 없이 진전 없음)
4. 에이전트가 끝나지 않음(도구를 계속 부름)
5. 처리하다 실패한 메시지가 사라짐
- 이 다섯 개는 몇 초 기다릴지, 몇 번 다시 할지, 몇 단계에서 멈출지를 숫자로 정해 코드 몇 줄로 막아요.

### 먼저 말 거는 에이전트(피클 · 뮤즈의 차별점)
- 시키지 않아도 할 만한 일을 찾아 제안해요. 너무 자주 말 걸면 알림을 끄고, 너무 안 걸면 있으나 마나예요.
- 영상 작성자 방식: 매시간 셀이 깨어나 제안할 거리를 찾아요. 제안할 거리는 코드가 고르고 AI는 문장만 써요.
- 규칙: 하루 몇 번까지 말 거는지, 밤에는 어떻게 하는지, 거절하면 언제까지 참는지.
- 뮤즈는 결과가 나와도 사용자를 부를 만한 일인지 한 번 더 판단해요. 말 걸 이유가 약하면 조용히 기록만 남겨요.
