# ADR 0002: LLM 공급자를 Anthropic Claude로 바꾼다

- 상태: 결정(2026-11-21)
- 결정한 사람: 사용자("api 요청은 우선 엔트로픽 내 api 키로 진행") → 리드

## 맥락
- v2 · v3는 OpenAI(langchain_openai)를 썼어요. AGENTS.md는 "공급자는 팀이 정한 하나만"이에요.
- v4 비서는 도구를 여러 번 부르는 대화와 구조화 출력이 많아요.
- v2 · v3 답을 공정하게 비교하려면 같은 공급자로 돌려야 해요.

## 결정
- 대화 · 구조화 출력 · 도구 루프는 모두 Claude예요(`agent/llm.py` 한 곳).
  - 비서: `claude-sonnet-5-5`
  - 짧은 일: `claude-haiku-5-5`
  - 판정: `claude-opus-5-5`
- 임베딩은 기존 공급자를 유지해요. 이미 넣은 벡터를 다시 만들지 않으려는 거예요.
- 되돌리기용으로 OpenAI 길은 설정으로 남겨요. 기본은 anthropic이에요.
- 강제 tool_choice가 400인 모델이라 auto + strict 도구를 써요.

## 결과
- 좋음: 비교 평가가 같은 조건이 돼요. 프롬프트 캐시로 비용이 줄어요.
- 비용: v2 · v3 지시문을 Claude에 맞게 다시 재야 해요. 이번 작업 비용 상한은 $50이에요.
- 팀 확인: 새 의존성(`anthropic`)과 공급자 변경은 팀 이슈로 알려요.
