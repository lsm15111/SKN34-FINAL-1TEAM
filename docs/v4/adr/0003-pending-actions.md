# ADR 0003: 되돌릴 수 없는 행동은 '대기 행동'으로만, 비서는 흐름 층 맨 위

- 상태: 결정(2026-11-21)

## 맥락
- 피클 사고(시키지 않은 전화)처럼, 에이전트의 잘못된 행동은 밖으로 나가요.
- AGENTS.md 4절은 "에이전트는 DB에 쓰지 않고 확정 · 저장 권한이 없다"예요.

## 결정
- 비서의 제안 도구는 `assistant_actions` 행(proposed)만 만들어요.
- 사람이 [승인]하면 `actions.execute`가 실행해요.
  1. 조건부 UPDATE로 approved
  2. 기능 service 실행과 같은 트랜잭션에서 executed
- 막는 장치
  - 멱등 키: 같은 승인 두 번이면 같은 결과
  - 만료: 기한 뒤면 409
  - 대상 버전: 본 견적 · 공정표 판이 바뀌면 failed
  - 대상마다 열린 승인은 하나
- 층: `assistant`는 흐름 층 맨 위(chat 위)에 두고, `main.py` · `worker.py`만 import해요. 기능 모듈은 비서를 몰라요.
- LLM 출력으로 사용자 · 공사 id를 받지 않아요. 도구는 ref(v1 · s1 등)만 받아요.

## 결과
- 좋음: 승인 없는 실행이 구조적으로 불가능해요. 레드팀 기준이 분명해요.
- 비용: 승인 카드 UI와 만료 · 실패 처리가 필요해요.
