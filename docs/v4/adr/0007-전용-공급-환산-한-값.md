# ADR 0007: 전용 → 공급 환산은 한 값(1.315)을 쓴다

- 상태: 계산 엔진에 넣음(2026-11-24, 고침 갈래 FB 계산 · 보드). 리드 확인(11-24): 한 값 1.315로 가요. 크기별 값(1.376 · 1.315 · 1.223)은 큰 집 오차가 보이면 다시 정해요
- 근거 자료: `data/v3/area/exclusive_ratio.csv` · `area_rules.json`(공개 분양 · 임대 공고 평면 20곳, 2026-11-11 수집)
- 계기: QA 6차 c2 고칠 것 1(`d10-/reports/v4 비서 에이전트/qa/r6/c2-반셀프조건.md`)

## 맥락
- 계약서 전용 84㎡를 넣으면 집 정보가 '전용 84.0㎡ · 30.5평'으로 보였어요. 84㎡형은 보통 33~34평형이에요.
- 같은 집인데 환산이 곳마다 달랐어요.

| 쓰는 곳 | 값 |
| --- | --- |
| 내 집 평 · 부자재 · 퍼티 · 가견적 '공급 평' 수량(`refprice/house.py` HOUSE_2026H2) | 1.2 |
| 도배 면적 회귀 · 방 개수 기본값(`refprice/book.py` 2026H2-rooms 뒤 판) | 1.315 |
| 목공 몰딩 · 걸레받이 길이 · 평탄화 면적(MOKGONG_2026H2) | 1.2 |
| 시세 범위(`calc/market_band.py` · `calc/quick_budget.py`) | 1.2 |

- 그래서 한 집의 평은 30.5평(× 1.2)인데 도배 면적은 33.4평(× 1.315)으로 셌어요.

## 근거(평면 20곳, 공급 ÷ 전용)

| 값 | 공급 오차(가운데 · 평균 · 최대) | 평 오차 가운데 | 전용 59 · 84 · 101.5㎡ → 평 |
| --- | --- | --- | --- |
| 1.2 | 8.7% · 8.2% · 14.0% | 2.5평 | 21.4 · 30.5 · 36.8 |
| 1.315 | 3.8% · 4.1% · 16.1% | 1.0평 | 23.5 · 33.4 · 40.4 |
| 공고 실제(같은 전용) | - | - | 23.8~25.3 · 32.6~34.3 · 38.1 |

- 20곳 가운데 1.315. 크기별 가운데는 전용 50㎡ 미만 1.376(1곳) · 50~60㎡ 1.376(6곳) · 60~85㎡ 1.315(7곳) · 85㎡ 초과 1.223(6곳)이에요.
- 흔한 평형 표기: 전용 59㎡ = 24평형, 84㎡ = 33~34평형. 1.2는 둘 다 3평쯤 작게 봐요.
- 도배 면적 회귀(공급 × 1.55 + 방 × 20.4㎡)를 맞춘 평면도 같은 20곳이라, 도배 금액의 큰 몫(면적)은 이미 1.315예요.

## 결정
1. 한 값 `calc.common.SUPPLY_PER_EXCLUSIVE = 1.315`. 지금 쓰는 판은 모두 이 값이에요.
   - 집 크기 새 판 `HOUSE_2026_11`(2026.11, `HOUSE_DEFAULT`), 목공 새 판 `MOKGONG_2026_11`(2026.11, `MOKGONG_DEFAULT`)
   - 도배 새 판 `2026.11c-market` · `2026.11c-remodel`: 줄 값은 2026.11b와 같고 '공급 평' 수량이 1.315를 따라가요.
   - 시세 범위(market_band · quick_budget)도 이 값을 써요.
2. 판 고정
   - 표준견적서는 도배 · 목공 판(price_ver)이 바뀌어 다음에 열 때 새 버전을 쌓아요. 저장한 옛 버전은 그대로예요.
   - 요청 때 고정한 가견적(`visits.estimate_total`)은 그대로예요.
   - 산식 버전(2026.11.2)은 올리지 않아요. 올리면 예상 공정표가 다시 세어져 시작일이 바뀔 수 있어요(ADR 0006 리드 결정과 같음).
   - 옛 판(HOUSE_2026H2 · MOKGONG_2026H2 · 2026.11b-*)은 기록으로 남아요. v2 미리보기 · 업체 단가표 예시는 옛 판 그대로예요.
3. 같은 판에 넣은 것: 전체 철거면 '기존 벽지 철거' 줄을 '안 함'(전체 철거 공사에서 떼요)으로 둬요.
   - 앞 판은 철거 범위와 상관없이 늘 '실측 후'였어요(QA r6 화면 M9).
   - 리모델링 기준의 근거인 서울 업체 실견적 235건은 모두 철거 공사가 따로라 도배 소계에 벽지 떼기가 없어요.
   - 부분 철거 · 철거 안 함은 그대로 '실측 후'예요. 덧방 여부 · 벽지 겹 수는 실측에서 정해요.
   - 합계에는 어느 쪽도 들어가지 않아 금액은 같아요.

## 바뀌는 숫자(전용으로 넣은 집만, 실크 · 빈 집 · 도배만 하는 공사 기준, 부가세 포함)

| 집 | 평 | 표준견적서 | 벽지 직접 구매 |
| --- | --- | --- | --- |
| 전용 84㎡ | 30.5 → 33.4 | 3,027,474 → 3,049,485(+22,011) | 1,990,518 → 2,012,529 |
| 전용 59㎡ | 21.4 → 23.5 | 2,346,146 → 2,362,085(+15,939) | - |
| 전용 101.5㎡ | 36.8 → 40.4 | 3,750,786 → 3,778,110(+27,324) | - |
| 공급 112.4㎡(34평) | 34 → 34 | 3,091,076 그대로 | - |

- 차이는 부자재 줄(공급 평 × 6,900원)이에요. 도배 면적 · 벽지 · 품은 그대로예요.
- QA c2(34평 → 계약서 전용 84㎡): 앞 판은 −63,602원, 새 판은 −41,591원이에요. 남은 차이는 전용 84 × 1.315 = 110.5㎡가 34평(112.4㎡)보다 작아서예요.
- 목공(몰딩 · 걸레받이, 전용 84㎡): 1,275,843 → 1,398,150원. 평탄화(공급 112.4㎡): 988,842 → 904,386원(전용 = 공급 ÷ 1.315).

## 남은 한계
- 한 값이라 큰 집(전용 85㎡ 초과)은 평을 2~4평 크게 봐요(전용 101.5㎡ → 40.4평, 공고 38.1평). 크기별 값(1.376 · 1.315 · 1.223)으로 바꿀지는 평면을 더 모은 뒤 정해요.
- 평면 20곳이 공공 분양 · 임대라 민간 단지는 전용률이 달라 공급이 더 클 수 있어요.
- 업체 화면(작업함 · 요청)의 평은 저장한 표준견적서 평이라, 고객이 표준견적서를 다시 열기 전까지 옛 평이 보일 수 있어요.
