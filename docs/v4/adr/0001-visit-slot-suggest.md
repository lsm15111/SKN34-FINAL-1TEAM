# ADR 0001: 비서가 실측 시간 후보를 제안한다

- 상태: 결정(2026-11-21)
- 결정한 사람: 사용자 요청 "실측 일정 잡는 것도 사용자에게 추천하거나 미리 일을 도와줘야 해" → 리드

## 맥락
- AGENTS.md 1절(초기)은 "실측 요청은 연결만 하고 방문 날짜 · 기한을 다루지 않는다"였어요.
- 팀 dev 병합 뒤 v3에는 반나절 단위 실측 일정 고르기(업체 후보 → 고객 고르기)가 이미 있어요.
- v4는 비서가 일을 미리 돕는 서비스예요.

## 결정
- 비서가 고객 가능 시간(기억 · 대화)과 업체 빈 반나절을 겹쳐 후보 2~3개를 **제안**해요.
- 고르기는 사람이 [승인]으로 해요. 실행은 기존 `visit.flow.pick` · `pick_proposal`이 해요.
- 후보 계산은 `calc.slots`(순수 함수)가 해요. LLM은 날짜를 만들지 않아요.

## 결과
- 좋음: 고객이 일정을 정하는 시간이 줄어요. 날짜는 계산 엔진 한 곳에서만 나와요.
- 비용: 업체 빈 시간을 읽는 함수(`open_halves_for`)가 새로 필요해요.
- 팀 확인: AGENTS.md와 다른 점이라 팀 PR 때 이 문서를 붙여요.
