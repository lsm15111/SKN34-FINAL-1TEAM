## 3. 사용자 흐름(화면)
- 무료 모드(오전)
  - F1 처음 고객: 손님 첫 대화 → 표준견적서 → 가입 → 업체 추천 → 실측 요청 → 반나절 → 견적 비교 → 업체 확정 → 날짜 수락 → 확정 공정표까지 갔어요. 승인 카드 4번 · 먼저 말 걸기 3번이에요.
  - F2 도배 업체: 가입 → 관리자 승인 → 단가 확인 → 요청 브리핑 → 기간 답하기 → 반나절 수락 → 견적서 체크리스트 → 공사 날짜 보내기까지 갔어요. 승인 카드 2번 · 비서 소식 2번이에요.
  - F3 반셀프: 범위 밖(콘센트) 안내는 맞았어요. 직접 칠하기 질문 · 날짜 미루기 · 기억은 무료 모드에서 막혔어요.
  - 흐름에서 찾은 문제 16개는 고침 담당에게 나눠 맡겼어요(작업 폴더 `flows/README.md` 표).
- LLM 모드(오후, 새 시험 고객 L1 · L3): 세 흐름 모두 끝까지 갔어요(F1 확정 공정표 · F2 공사 날짜 보내기 · F3 직접 할 일까지). 비용은 $0.18이고, L1은 상품 하루 상한 $0.40의 36%를 썼어요.
  - 결론부터 짧게 답하고, 말로 요청해도 승인 카드로 이어지고, 도면 찾기는 출처와 함께 링크만 줘요(그림 저장 0).
  - 찾은 문제 21개 중 큰 것: 기억 검사(오늘 고침) · 공사 날짜가 같은 업체 다른 공사와 겹침 · 같은 수락 단추 두 개 · 폰 375px 카드 넘침 · 처리한 줄이 기록에서 사라짐(작업 폴더 `flows/README-llm.md`)
