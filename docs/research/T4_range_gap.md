## 1. 견적 정확도 단계 프레임

### 1.1 AACE International 비용 견적 등급 — 원문 확인

AACE 견본 PDF(목차 + 본문 일부, Table 1 포함)를 내려받아 텍스트로 확인했다.

**18R-97 (공정 산업: Process Industries), Rev. 2020-08-07** — [AACE 18R-97 견본 PDF](https://web.aacei.org/docs/default-source/toc/toc_18r-97.pdf) [공식]

| Class | 정의 성숙도(완성도 %) | 용도 | 대표 방법 | 기대 정확도(80% 구간) |
|---|---|---|---|---|
| 5 | 0~2% | 개념 검토 | 용량 계수, 파라메트릭, 판단, 유추 | L −20~−50% / H +30~+100% |
| 4 | 1~15% | 타당성 검토 | 장비 계수, 파라메트릭 | L −15~−30% / H +20~+50% |
| 3 | 10~40% | 예산 승인 · 통제 | 반상세 단가(조립 단위 줄) | L −10~−20% / H +10~+30% |
| 2 | 30~75% | 통제 · 입찰 | 상세 단가 + 강제 상세 수량산출 | L −5~−15% / H +5~+20% |
| 1 | 65~100% | 검증 견적 · 입찰 | 상세 단가 + 상세 수량산출 | L −3~−10% / H +3~+15% |

**56R-08 (건축 · 일반 건설: Building and General Construction), Rev. 2020-08-07** — [AACE 56R-08 견본 PDF](https://web.aacei.org/docs/default-source/toc/toc_56r-08.pdf) [공식]
→ **믿집(아파트 인테리어)에는 18R-97보다 56R-08이 맞다.**

| Class | 성숙도 | 용도 | 대표 방법 | 기대 정확도(80% 구간) |
|---|---|---|---|---|
| 5 | 0~2% | 기능 면적 · 개념 검토 | **SF/m² 계수**, 파라메트릭, 판단, 유추 | L −20~−30% / H +30~+50% |
| 4 | 1~15% | 계획설계 · 개념 검토 | 파라메트릭, 조립 단위 모델 | L −10~−20% / H +20~+30% |
| 3 | 10~40% | 설계 발전 · 예산 승인 | 반상세 단가(조립 단위 줄) | L −5~−15% / H +10~+20% |
| 2 | 30~75% | 통제 · 입찰 | 상세 단가 + 강제 상세 수량산출 | L −5~−10% / H +5~+15% |
| 1 | 65~100% | 검증 · 입찰 직전 · **변경 지시** | 상세 단가 + 상세 수량산출 | L −3~−5% / H +3~+10% |

원문에서 확인한 해석 포인트:
- **등급을 정하는 1차 기준은 '정의 성숙도' 하나뿐**이다. 정확도와 방법은 2차 특성이다. [공식]
- ±값은 **적절한 예비비(contingency)를 넣은 뒤**, 실제 비용이 견적에서 벗어나는 정도를 80% 신뢰구간으로 나타낸 값이다. 예비비는 보통 초과 · 미달 확률이 50:50이 되게 잡는다. [공식]
- 표는 '범위의 범위(range of ranges)'다. 같은 Class 5라도 반복 사업이면 Class 3만큼 정확할 수 있다. 56R-08은 Class 5가 −30%/+50%처럼 넓을 수도, −20%/+30%처럼 좁을 수도 있다고 쓴다. [공식]
- **관리가 약하거나 복잡 · 위험한 프로젝트는 상한이 표의 2~3배**가 될 수 있다(연구 인용). → 믿집 표시 문구에 '범위 밖이 될 수 있는 경우'를 미리 적어야 한다는 근거다. [공식]
- 정의 성숙도만으로 정확도가 정해지지 않는다. 시스템 위험(기술 복잡도, 참고 데이터 품질, 조직 압력 등)은 위험 분석으로 따로 다룬다. [공식]
- 2차 자료(epcland 등)는 Class 4 값을 다르게 쓰기도 한다(`상충`). 이 문서는 위 원문 표를 따른다. [커뮤니티]
- ASTM E2516도 같은 분류 체계를 채택했다(Class 5 = 정의 수준 최저). [ASTM E2516-11 견본](https://cdn.standards.iteh.ai/samples/77722/609c1509d60b44a3906c51f6e7773328/ASTM-E2516-11.pdf) [공식]

### 1.3 국내 건설의 개산견적 · 상세견적 — `미확인`(공식 정의 원문 못 찾음)

일반적으로 쓰이는 뜻(실무 통념):
- **개산견적(概算)**: 기획 · 계획 단계에서 단위면적당 공사비(평당 · ㎡당)나 유사 실적으로 내는 대략 견적. AACE Class 5~4에 해당한다.
- **상세견적(明細)**: 설계도서로 수량을 산출(적산)하고 일위대가 단가를 곱해 내는 견적. 입찰 · 계약용이며 Class 2~1에 해당한다.
- 공공공사 예정가격은 표준품셈 · 표준시장단가 · 거래실례가격 · 견적가격으로 산정한다(국토부 자료 인용). [공식 · 검색 요약](https://www.molit.go.kr/USR/policyData/m_34681/dtl?id=201) `미확인`(원문 미열람)

### 1.4 참고 클래스 예측(Reference Class Forecasting, Flyvbjerg)

- 출처: Flyvbjerg, *From Nobel Prize to Project Management: Getting Risks Right*, Project Management Journal 37(3), 2006-08 — [arXiv 1302.3642](https://arxiv.org/abs/1302.3642) [학술]
- **3단계**: ① 비슷한 과거 사업의 참고 클래스를 고른다(통계적으로 의미 있을 만큼 넓고, 비교 가능할 만큼 좁게). ② 그 클래스의 결과 분포(예: 비용 초과율)를 만든다. ③ 이 사업을 그 분포 위에 놓고 받아들일 초과 위험에 맞는 증액(uplift)을 고른다.
- 수치 예: 도로 172건 참고 클래스에서 40%는 초과 10% 이하, 80%는 초과 32% 이하였다. 필요 증액은 이렇다.

| 사업 | P50(초과 위험 50%) | P80(20%) | P90(10%) |
|---|---|---|---|
| 도로 | +15% | +32% | +45% |
| 철도 | +40% | +57% | +68% |

- 포트폴리오가 큰 투자자는 P50, 위험을 피하려면 P80~P90을 쓰라고 권한다.
- **믿집 적용**: "같은 단지 · 비슷한 평형 · 비슷한 연식에서 실측까지 간 견적들의 '실측/표준' 비율 분포"가 참고 클래스다. 초기에는 외부 클래스(숨고 평균 · 최저 · 최고, 오늘의집 사례 금액)로 중심만 점검한다.

### 2.2 conformal prediction — 현황과 표본 수

- 보장: 보정 표본 n개 · 목표 1−α일 때 **1−α ≤ 적중률 ≤ 1−α + 1/(n+1)** 이 n과 무관하게 성립한다(교환가능성 가정, 평균적 보장). n=1000이면 실제 적중률이 대개 0.88~0.92에 들어온다(α=0.1). — Angelopoulos & Bates, [A Gentle Introduction to Conformal Prediction](https://arxiv.org/abs/2107.07511) [학술]
- 유한 구간 최소 n `계산`: ⌈(n+1)(1−α)⌉ ≤ n → **80%: n≥4, 90%: n≥9, 95%: n≥19**.
- 보정 표본별 '실제 적중률' 흩어짐(5~95%, Beta(n+1−l, l), l=⌊(n+1)α⌋) `계산`:

| n | 80% 목표 | 90% 목표 |
|---|---|---|
| 10 | 0.61~0.96 | 0.74~0.99 |
| 20 | 0.66~0.93 | 0.78~0.98 |
| 30 | 0.68~0.91 | — |
| 50 | 0.71~0.89 | 0.83~0.96 |
| 100 | 0.73~0.86 | 0.85~0.95 |
| 200 | 0.75~0.85 | 0.86~0.93 |
| 500 | 0.77~0.83 | 0.88~0.92 |

- **MAPIE**: 최신 1.6.0(2026-10-19), 1.0.0(2025-05-22), BSD-3-Clause. Python 요구는 메타데이터 ≥3.10, README ≥3.9로 `상충`. [PyPI](https://pypi.org/project/MAPIE/) [업계]
  - v1 회귀 클래스: `SplitConformalRegressor`, `CrossConformalRegressor`, `JackknifeAfterBootstrapRegressor`, `ConformalizedQuantileRegressor`(CQR), `TimeSeriesRegressor`.
  - 예측은 `.predict_interval()`이고, 지표는 coverage · mean width · 크기별 적중률이 있다. [MAPIE API](https://mapie.readthedocs.io/en/latest/api/) · [v1 릴리스 노트](https://mapie.readthedocs.io/en/v1.4.1/_sources/v1_release_notes.rst.txt) [업계]
- **crepes**: 표준 · 정규화 · **Mondrian(그룹별)** conformal 회귀와 예측 분포 시스템(cps=True)을 지원한다. 그룹(공정 · 평형대 · 연식)별로 보정하기 좋다. [crepes 논문(PMLR v230, 2024)](https://proceedings.mlr.press/v230/bostrom24a.html) · [PyPI](https://pypi.org/project/crepes/) [학술]
- 작은 표본에서는 split 방식이 보정용 데이터를 버리는 손해가 크다. k-fold(cross) 변형으로 줄일 수 있다. [arXiv 2006.16941](https://arxiv.org/pdf/2006.16941) [학술]
- 건설 · 인테리어 비용에 conformal을 적용한 2024~2025 논문은 검색 범위에서 찾지 못함 `미확인`.

### 2.3 베이지안 업데이트 — "데이터가 쌓이면 좁아진다"의 한계 `계산`

r = ln(실측 견적 / 가견적)이라 하자. 평균의 사전 sd 0.10, 관측 sd 0.10(알려졌다고 가정)인 정규–정규 모형에서 결과는 이렇다.

| 표본 n | 평균의 사후 sd | 예측 sd | 10~90% 범위 |
|---|---|---|---|
| 0 | 0.100 | 0.141 | −16.6% / +19.9% |
| 1 | 0.071 | 0.122 | −14.5% / +17.0% |
| 5 | 0.041 | 0.108 | −12.9% / +14.8% |
| 10 | 0.030 | 0.104 | −12.5% / +14.3% |
| 30 | 0.018 | 0.102 | −12.2% / +13.9% |
| 100 | 0.010 | 0.100 | −12.1% / +13.7% |

- 데이터는 **치우침(중심)** 을 빠르게 잡는다(5~10건). 하지만 **고유 흩어짐(σ)** 아래로는 범위를 못 좁힌다. 더 좁히려면 특징(연식 · 확장 · 업체)으로 흩어짐을 설명하거나 정보를 더 받아야 한다.
- σ 자체를 추정할 때 상대 표준오차는 약 1/√(2(n−1))다: n=10 24%, n=20 16%, n=30 13%, n=50 10%, n=100 7%.
- 작은 그룹(예: 40평대 목공 3건)은 **부분 풀링**(그룹 평균을 전체 평균 쪽으로 당김)으로 보호한다. [TFP 다층 모형 입문(Gelman radon 예)](https://www.tensorflow.org/probability/examples/Multilevel_Modeling_Primer) [업계]

### 2.4 몬테카를로 · 3점 추정 — 결정론 엔진에 넣는 법

- 엔진은 결정론이어야 한다. 몬테카를로는 **오프라인에서 시드 고정 · 준난수(Sobol)** 로 돌려 표(분위수 배수)를 만들고, 엔진은 표만 읽게 한다. 또는 아래처럼 해석적 · 수치적분으로 대신한다.
- '실측 후' 줄처럼 **할지 말지(베르누이 p) × 금액 범위**가 섞이면, 로그정규 본체와의 혼합 분포 CDF를 수치적분한 뒤 이분법으로 분위수를 찾는다. 무작위 없이 결정론으로 계산된다.
- 예 `계산`: 가견적 350만 원(σ 0.113)에 철거(할 확률 0.5, 14만~56만 원 균등)를 더하면:
  - 혼합 분포 P10~P90 = **314만~428만 원**
  - 현재 코드 방식(모르면 상한에만 더함) = 303만~461만 원
  → 확률을 알면 범위가 더 좁고 정직해진다. "다 하게 되면 최대 +56만 원"은 따로 표시한다.

**셀프 실측 가이드(믿집안)**:
1. 방마다 바닥 가로 · 세로를 레이저나 줄자로 잰다(몰딩 · 걸레받이 = 둘레, 도배 = 둘레 × 천장고 − 문 · 창).
2. 천장고는 1곳 이상 잰다(우물천장이면 2곳).
3. 문 폭 · 높이와 개수를 적는다.
4. 사진을 찍는다: 벽지 끝 들춘 곳(겹수 · 실크 여부), 곰팡이 · 결로 부위, 몰딩 단면, 걸레받이, 문틀, 천장 등박스.
5. AR 앱 값은 '참고'로만 받고 정밀도 등급은 self(σ 0.04~0.05)로 둔다.

- [ ] 몰딩 형태(평 · 계단 · 마이너스) · 길이(방 둘레) · 기존 몰딩 철거 난이도
- [ ] 걸레받이 재질(PVC/MDF) · 높이 · 길이(둘레 − 문 폭)
- [ ] 방문: 개수 · 규격 · 문틀 상태(교체 vs 필름), 문선, 바닥 단차 간섭
- [ ] 천장: 수평 · 처짐(레벨기), 석고보드 덧방 여부, 우물천장 · 등박스 철거, 매입등 타공 위치
- [ ] 자재 반입: 엘리베이터 · 보양 · 관리사무소 공사 신고 · 작업 가능 시간

### 6.4 업체가 실측 전에 알고 싶어 하는 정보(→ 믿집 브리프 항목)

- 주택 유형, **공급면적(서류 근거)**, 확장 여부, 층고, 거주 중/공실, 현장 상태(곰팡이 · 누수 · 들뜸), 현재 · 희망 벽지 종류, 천장 포함 여부, 실측 · 시공 희망일 — 숨고 [업계]
- 벽 치수와 천장고, 롤 수, 기존 벽지 제거 여부, 예상 못 한 문제가 생기면 추가 요금 기준 — Thumbtack [업계]
- 자재 · 치수 · 알려진 문제(사진 · 도면은 필수 아님) — Block [업계]

## 7. 믿집 제안

### (a) 범위 계산 설계

**원칙**
1. **로그정규 곱셈 모형 유지.** 금액은 양수이고 오른쪽으로 치우친다. AACE 범위도 위로 치우친다. 현재 코드의 σ² = Σ(수량 근거별) + σ단가²를 유지한다.
2. **P10~P90(80%)을 공식 구간으로 둔다.** AACE의 '80% 신뢰구간'과 같아서 외부 설명이 쉽다.
3. 범위를 넓히는 요인 세 가지와 분리 원칙:

| 구분 | 다루는 법 | 예 |
|---|---|---|
| ① 선택(고객이 정할 것) | 폭이 아니라 **시나리오 행** | 합지/실크, 천장 포함, 방문 교체/필름 |
| ② 불확실성 | 수량 · 단가 · 조건 σ | 면적 계수, 업체 단가, 철거 여부 |
| ③ 범위 밖 위험 | 금액 대신 **고지** | 누수 · 구조 · 철거 후 발견(AACE: 상한이 2~3배까지) |

**수량 불확실성(면적 계수 분포)**
- 도배 면적 = 공급면적 × k, ln k ~ N(ln 2.5 + 치우침, σ_k²).
- 근거(외부 값은 상충):
  - 분양평수 × 2.5(또는 실평수 × 3), 확장 ±5%(숨고 2026-06-11 [업계])
  - 분양 × 2.5, 전용 × 3~3.5, 실평수(천장 포함) × 3.5~4(2005 카페 글, 참고용 [커뮤니티](https://m.cafe.daum.net/sso0525/MVN2/128))
  → band σ 0.10~0.15가 타당하다(현재 0.14).
- 몰딩 '공급 1평당 2.4 m'는 외부 근거를 못 찾았다 `미확인`. AI Hub 평면도로 공급평당 둘레 분포를 뽑아 검증할 것을 권한다.
- 같은 근거(면적 · 둘레 · 천장 · 문)의 줄은 완전 상관, 다른 근거끼리는 독립(현재 코드)으로 둔다. 평형을 안 뒤에는 잔차 상관이 작아 큰 문제가 없다.

**단가 분포(공공 기준 vs 시장 관측)**
- 중심 = 공공 기준 × `price_center`.
- 공공 기준 구성: 소규모 인테리어는 **표준품셈 품 × 시중노임단가 + 자재(조달청 · 물가지)** 를 1차로 쓰고, 표준시장단가는 교차 확인용으로만 쓴다(100억 원 이상 공사 단가라 규모 차이가 있음).
- `price_center` 사전값 제안:
  - 도배 1.05~1.10. 근거: 노임은 기본급여만, 시장 일당 20만~30만 원(블로그) ÷ 229,833원 ≈ 1.09, 숙련 15% 가산 허용.
  - 목공 `미확인`.
  - 표준견적서가 간접비 · 이윤을 이미 얹는지에 따라 달라지므로 먼저 확인한다.
- σ단가: 도배 일당 20만~30만 원을 P10~P90으로 보면 σ ≈ 0.16, 몰딩 m당 1.5만~3.5만 원이면 σ ≈ 0.33 `계산`. 현재 값(도배 0.20 · 목공 0.25)은 이 사이에 있어 타당하다.
- **가견적 단가가 들어오면(업체 10곳+)** `price_center` · `price_sigma`를 가장 먼저 보정한다. 실측 견적보다 빨리 쌓이는 '시장 관측'이기 때문이다.

**조건 불확실성('실측 후' 줄)**
- 지금: 하기로 함 → 하한 · 상한 모두에, 모름 → 상한에만(보수적, AACE식 비대칭). 콜드스타트에는 적절하다.
- 개선: 줄마다 **할 확률 p**를 둔다(사전값은 연식 · 질문 답 · 사진, 나중에는 데이터). 로그정규 본체와 혼합한 분위수를 수치적분으로 결정론 계산한다(2.4절 예: 303만~461만 원 → 314만~428만 원). '다 하면 최대 +X'는 별도 줄로 남긴다.
- 금액 범위 근거: 숨고 9종 표(6.2절)와 HomeGuide 제거 · 보수 단가로 `CondRule` low/high 출처를 '팀 가정값'에서 바꾼다(부록 A).

**단계마다 좁아지는 구조(보이는 약속)**

| 단계 | 정보 | σ(도배 예) | 표시 범위 | AACE |
|---|---|---|---|---|
| 표준견적서 | 평형대 | 0.244 | 256만~479만 원 | 5 |
| + 주소 → 대장 면적 | area | 0.215 | 266만~461만 원 | 4~5 |
| + 업체 단가(가견적) | vendor | 0.113 | 303만~405만 원 | 3 |
| + 셀프 실측 · 사진 | self | 0.089 | 312만~393만 원 | 3~2 |
| 실측 견적 | visit | 점 | 예: 368만 원 | 2 |

(중심 350만 원, 부가세 포함, 조건 줄 제외) `계산`

- 정보가 늘면 범위는 좁아지거나 **옮겨진다**(예: 철거하기로 하면 하한이 오름). 옮겨질 때는 이유를 같이 보여 주고, 범위 변화 이력을 남긴다.
- 실측 견적 이후 범위(정산 대비, Class 2 −5~−10% / +5~+15%)도 데이터로 추적한다.

### (b) 표시 문구 예

**표준견적서 카드**
```
도배 예상 범위 (부가세 포함)
256만 ━━━━━━━━●━━━━━━━━━━ 479만 원
            가운데 350만 원
같은 조건이면 10집 중 8집이 이 범위에 들어올 것으로 봐요.
기준: 34평(공급 112㎡) · 실크 · 천장 포함 · 공실

범위를 넓히는 이유
 ① 업체마다 다른 단가 67%      → 업체 단가를 받으면 285만~430만 원
 ② 평형으로 어림한 면적 33%    → 주소로 면적을 확인하면 266만~461만 원
   (둘 다 하면 303만~405만 원)
'실측 후' 줄
 · 기존 벽지 철거: 아직 몰라요. 하게 되면 14만~56만 원 더 들어요(범위 위쪽에만 넣었어요).

이 범위는 공공 기준 단가(2026.9.1 시중노임단가 · 2026 표준품셈)와
믿집 가정값(2026H2-r1)으로 만들었어요. 아직 실측 견적으로 맞춰 본 적 없는 값이에요.
누수 · 곰팡이 · 구조 문제가 나오면 범위 밖이 될 수 있어요.
```

**데이터가 쌓인 뒤 근거 문구**
- "믿집에서 실측까지 마친 30평대 도배 42건으로 맞춘 범위예요(2027-03 보정)."
- "지난 3개월 실측 견적의 81%가 범위 안이었어요."

**가견적 카드**
```
○○도배 가견적 368만 원 (업체가 단가를 확인했어요 · 셀프 실측 반영)
실측 후 예상 328만~413만 원
이 업체의 가견적–실측 차이: 평균 +2% (12건)
```

**용어 원칙**: '예상 · 대부분 · 10집 중 8집'을 쓰고 '보장 · 확정'은 쓰지 않는다. 설명문은 AI가 쓰고 금액은 계산 엔진이 냈다고 밝힌다(HomeAdvisor의 '자동화로 작성 · 검수' 고지와 같은 방식).

### (c) 데이터 플라이휠 — 실측 견적이 쌓이면 보정

**기록할 것**(견적 단계마다)
- 범위 결과: 버전, 입력(평형 · 면적 근거 · 정밀도 · 조건 상태), 출력(low · mid · high · σ · 폭 기여도)
- 이후 결과: 가견적 단가 · 금액, 실측 견적 금액 · 부가세 방식 · 기간, 차이 사유 코드(구조화), 정산 금액(있으면), 지역 · 연식 · 업체

**지표**
- 적중률(목표 80%)
- 구간 점수 IS = (u−l) + (2/α)(l−y)·1[y<l] + (2/α)(y−u)·1[y>u] — 좁고 맞는 범위일수록 낮음(Gneiting & Raftery 2007, 링크 `미확인`)
- 로그 오차 중앙값
- 그룹별 치우침(공정 · 평형대 · 연식 · 업체)

**보정 순서**

| 데이터 | 보정 대상 | 방법 | 주기 |
|---|---|---|---|
| 가견적 단가 10건+/공정 | `price_center` · `price_sigma` | 정규–역감마 사후(닫힌형), 업체 간 흩어짐 = σ단가 | 30건마다 |
| 실측/가견적 10~50건 | `visit_sigma` · 치우침 | 위와 같음 + 공정 · 평형대 부분 풀링 | 월 1회 |
| 실측/표준 mid 50~200건 | 단계별 구간 배수 | split conformal(로그 잔차, Mondrian 그룹) 오프라인 → 상수표 | 분기 1회 |
| 수백 건+ | 특징 기반 폭 | 분위수 GBM + CQR(MAPIE) | 반기 |

**운영 원칙**
- 보정 결과는 `RangeRules` **새 버전**으로 발행한다(예: 2027H1-r1, sources에 "실측 견적 N건(기간)"). 엔진은 상수만 읽어 결정론을 유지한다.
- 물가 변동이 있으면 교환가능성이 깨지므로, 노임 · 표준시장단가 공표(1/1 · 5월 · 9/1)마다 구간을 재점검한다.
- 치우침 경계:
  - 실측까지 가는 고객은 표본이 치우친다.
  - 업체가 가견적을 낮게 냈다가 실측에서 올리는 전략을 쓸 수 있다 → **업체별 가견적–실측 차이 이력을 공개**하면 유인을 바로잡을 수 있다(빈 파일 `vendor_score.py`의 후보 지표).

### (d) 사진 · 도면 · 셀프 실측으로 '실측 후' 줄 줄이기

| '실측 후' 줄 / 수량 | 가장 싼 정보원 | 정밀도 변화 |
|---|---|---|
| 면적 근거(평형 혼동) | 주소 + 동 · 호 → 건축HUB 전유공용면적 → 전용 · 공급 확정 | band → area |
| 기존 벽지 철거 | 벽지 끝 들춘 사진 + 질문 3개(실크인지 · 겹수 · 들뜸). 실크면 철거 필수 [업계] | open → yes/no |
| 곰팡이 · 결로 · 누수 | 창가 · 북측 벽 사진, 연식(K-apt 사용승인일) | p 갱신 |
| 퍼티 · 평탄화 | 손전등을 비스듬히 비춘 벽 사진 | p 갱신 |
| 짐 이동(거주/공실) | 질문 1개 | open → yes/no |
| 폐기물 | 철거 범위에서 자동 파생 | 계산 |
| 몰딩 · 걸레받이 길이 | 평면도 인식(방 둘레) 또는 셀프 실측 · RoomPlan | band → self |
| 방문 수 · 규격 | 평면도(문 클래스) + 줄자(폭 · 높이) + 문틀 사진 | guess → self |
| 천장 평탄화 · 철거 | 천장 사진(등박스 · 우물천장), 연식, 레벨 앱 참고 | guess → self(부분) |
| 몰딩 철거 | 몰딩 단면 사진(평 · 계단 · 마이너스) | open → yes/no |

- 비전 · LLM은 **'제안'만** 하고 고객이 확인한 답만 엔진에 넣는다(금액은 엔진만).
- 무엇을 먼저 물을지는 '폭을 가장 많이 줄이는 질문 ÷ 고객 수고' 순서로 정한다(현재 `Part.low_if/high_if`로 계산 가능).
- 업체에는 정밀도 표시가 붙은 브리프를 보낸다(예: "면적: 건축물대장 전용 84.97㎡, 셀프 실측 안 함"). 업체가 가견적 때 조건 줄마다 '포함/별도/금액'을 반드시 고르게 하면 실측 전 차이가 줄어든다.

### (e) 실측 견적이 범위 밖일 때 '차이 설명' 구조

실측 견적 파일에서 칸으로 받는 것은 금액 · 부가세 방식 · 기간뿐이다. 그래서 **범위 밖이면 업체가 사유 코드를 1개 이상 고르게** 하고(선택 입력: 실측 도배 ㎡ · 몰딩 m), 나머지는 자동으로 계산한다.

**차이 설명 카드**
```
실측 견적 428만 원 — 예상 범위(303만~405만 원)보다 23만 원(6%) 높아요   [범위 밖]
가견적 350만 원에서 이렇게 달라졌어요
  350  가견적
  + 0  ① 부가세 방식 맞춤 (둘 다 포함으로 환산)          자동
  +25  ② '실측 후' 줄 확정: 기존 실크 철거 (범위 상한 56만 안) 업체 선택
  +18  ③ 수량: 도배 면적 281 → 296㎡ (+15㎡ × 가견적 단가)  업체 입력
  + 0  ④ 단가 · 자재 변경                                업체 선택
  + 0  ⑤ 일정 할증 (기간 3일 → 2일: 인원 추가 여부)        자동 감지
  +35  ⑥ 설명되지 않은 차이 → 업체에 물어볼 질문 ↓
  ────
  428  실측 견적
물어볼 질문: "남은 35만 원은 어떤 작업인가요?" · "면적 296㎡는 천장 포함인가요?"
이 차이는 범위를 고치는 데 써요(동의 시).
```

- 순서는 항상 같다: 부가세 정규화 → 확정된 조건 줄 → 수량 → 단가 · 자재 → 일정 · 할증 → 최소 금액 · 출장비 → 미설명 잔여.
- '미설명 잔여'는 질문으로 바꾸고(LLM은 문장만 씀), 금액 귀속은 엔진이 한다.
- 범위 안이면 "예상 범위 안이에요(가운데보다 +5%)"만 짧게 보여 준다.
- 표현은 중립으로 쓴다(업체를 탓하지 않음). 범위를 잘못 잡은 탓이면 "우리 가정값을 고칠게요"라고 쓴다.
- 기록된 사유 코드별 금액은 플라이휠에서 어느 σ(수량 · 단가 · 조건)를 고칠지 정하는 입력이 된다.

### 간격 줄이기 기능 추천 5개(우선순위)

1. **주소 → 호별 면적 자동 확정**(건축HUB 전유공용면적 + K-apt 단지 정보): 평형 혼동을 없애고 연식으로 조건 사전확률을 잡는다.
2. **가견적 때 '실측 후' 줄 강제 응답 + 업체 변동 상한**: 줄마다 포함/별도/금액을 받고, "실측 후 ±10% 넘으면 사유 코드" 규칙을 둔다. 업체별 가견적–실측 차이 이력을 공개한다.
3. **3분 셀프 실측 + 사진 체크리스트**(줄자 · 레이저 우선, RoomPlan은 참고): 몰딩 · 걸레받이 · 방문 · 천장을 band/guess에서 self로 올린다.
4. **범위 밖 차이 설명 카드**(브리지 + 질문 생성): 고객 불신을 줄이고, 사유 코드 데이터를 쌓는다.
5. **보정 파이프라인**(가견적 단가 → 베이지안, 실측 50건+ → conformal 상수표, 버전 발행 · 적중률 공개).
   - 추가 후보: AI Hub 평면도로 계수 분포 학습 → 몰딩 '1평당 2.4 m' 검증.

## 부록 B. 결정론 계산용 공식 메모

- **로그정규 구간**: [c·e^(−zσ), c·e^(zσ)], σ = √(Σ_g (w_g σ_g)² + σ_p²), w_g = 근거 g의 금액 비중(현재 코드와 같음).
- **혼합 분위수**(조건 줄 확률 p): F(x) = Π 조건 조합의 확률 × P(L + Σ U_k ≤ x). 조건 k ≤ 6이면 2^k 조합을 열거하고, U는 구간 적분(중점 200칸)으로, 분위수는 이분법 80회로 구한다. 난수가 없다.
- **정규–역감마 갱신**(r = ln 비율): κn = κ0+n, μn = (κ0μ0 + n·r̄)/κn, an = a0+n/2, bn = b0 + ½Σ(r−r̄)² + κ0·n(r̄−μ0)²/(2κn). 예측 분포는 t(2an, μn, bn(κn+1)/(an·κn)). 순수 파이썬에서 t 분위수는 이분법으로 구하거나 정규 근사로 대신한다.
- **split conformal(오프라인)**: 보정 표본의 s_i = |ln(y_i/ŷ_i)|에서 q = ⌈(n+1)(1−α)⌉번째 값을 고르고, 구간은 [ŷe^(−q), ŷe^(q)]. 그룹별(Mondrian)로 q를 저장해 상수표로 쓴다.
