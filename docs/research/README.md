## 읽을 때 주의

- **세션 공용 웹 검색 한도가 조사 중간에 소진**되어, 뒤쪽 항목은 이미 찾은 URL을 직접 여는 방식으로만 확인했다. 그래서 `미확인` 표시가 남아 있다.
- 네이버 카페 · 지식iN · 오늘의집 노하우 일부는 로그인 · 차단으로 원문을 못 열고 검색 요약으로만 봤다(`요약 경유`).
- 숨고 블로그 가격 글 일부는 AI 생성 표기가 있고 같은 글 안에서도 값이 다르다. 시세는 **범위 · 날짜 · 출처 등급**과 함께만 쓴다.
- 법령은 국가법령정보센터 원문(조문 · 별표)을 열어 확인했다(T1). 그래도 법률 자문이 아니므로 화면에서는 단정하지 않고 확인처를 안내한다.
- 각 파일의 `상충` · `미확인` 목록은 데이터에 넣을 때 `conflict` 표시나 '확인 필요'로 옮긴다.
- 출처 key 규칙(데이터 파일과 연결): `S-T<트랙>-<출처 번호>` — 예: T2의 S11-a → `S-T2-11A`.
