# 읽기 지시 (1차 · 2차 공통)

스캔된 한국어 인테리어 책을 쪽마다 직접 눈으로 읽어 검색용 JSON으로 옮긴다.

- 이 자료는 공유 금지다. 작업 폴더(`data/local/sigong_ilji`) 밖으로 내용을 보내거나 저장하지 않는다. 웹 검색 · 외부 전송 금지.
- OCR 프로그램(Windows OCR, tesseract 등)은 쓰지 않는다. Read 도구로 이미지를 직접 본다.
- 먼저 `SPEC.md`(규칙)를 끝까지 읽는다. 규칙은 SPEC이 정본이다.
- `map.json`에서 맡은 쪽의 `part` · `q` · `kind` · `note`를 본다. Q 제목 · 인터뷰 여부는 여기를 따른다.

## 쪽마다

1. `img/pNNNL.png` → `img/pNNNR.png` 순서로 본다.
2. 숫자 · 표 · 각주 · 작은 글자는 300dpi로 잘라 다시 본다. 자른 이미지는 `crop/` 폴더에만 둔다.
   `python -I -c "import pymupdf; d=pymupdf.open(r'<원본 PDF>'); p=d[N-1]; p.get_pixmap(dpi=300, clip=pymupdf.Rect(x0,y0,x1,y1)).save(r'crop/pNNN_a.png')"`
   (쪽 크기 841 × 595pt, 왼쪽 반쪽 x 0~420, 오른쪽 반쪽 x 420~841)
3. 앞 쪽에서 이어진 글이면 앞 쪽 이미지에서 소제목을 확인한다.
4. 출력 폴더에 `pNNN.json`(세 자리 쪽 번호)을 UTF-8로 쓴다. 모양은 SPEC의 "쪽 JSON".
5. 글이 없는 쪽이면(map이 text true여도 실제로 없으면) 파일을 만들지 않고 보고에 적는다.

## 꼭 지킬 것

- 원문 그대로. 요약 · 의역 · 맞춤법 교정 금지. 원문 오탈자도 그대로 두고 보고에 적는다.
- 사례 인용 · 인터뷰의 닉네임 · 이름 · 계정은 적지 않는다. 출처 줄에는 원문에 있는 시공 방식과 집 정보(가구 수 · 평형 · 준공 연도)를 남긴다. 없는 시공 방식은 추정하지 않는다(`SPEC.md`의 사례 인용 규칙).
- `hints`는 고객 말투 질문 1~2개, 청크에 답이 있는 것만.
- 다른 출력 폴더(1차면 `b/`, 2차면 `a/`)는 열지 않는다. 따로 읽어야 비교가 된다.

## 끝나면

- 쓴 파일마다 `python -I -c "import json,sys; [json.load(open(f,encoding='utf-8')) for f in sys.argv[1:]]" <파일들>`로 JSON이 열리는지 확인한다.
- 마지막 답으로 짧게: 쪽별 청크 수, 만들지 않은 쪽과 이유, 읽기 어려웠던 곳(쪽 · 위치 · 고른 읽기), 원문 오탈자로 보이는 곳.
