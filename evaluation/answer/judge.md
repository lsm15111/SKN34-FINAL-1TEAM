# 답 품질 판정 기준 (v1, 2026-11-13)

판정자는 답마다 아래를 JSON으로 남긴다. 근거는 그 질문에서 **보여 준 조각(`shown`)의 글**만 본다. 판정자의 상식으로 맞다고 보더라도 조각에 없으면 '근거 없음'이다.

## 1. 문장 판정 (`claims`)
답을 문장으로 나눠, 사실을 말하는 문장만 판정한다. 인사 · 공감 · "업체에 물어보세요" 같은 안내 · '다음에 할 일' 줄은 빼고 `skip`으로 센다.
- `supported`: 보여 준 조각이 그 내용을 직접 말한다
- `partial`: 조각과 맞지만 조각에 없는 단정 · 숫자 · 조건을 덧붙였다
- `unsupported`: 조각에 없거나 조각과 다르다

## 2. 인용 판정 (`cites`)
문장 끝 `[K번호]`마다 그 조각이 그 문장을 받치는지 `ok` / `bad`.

## 3. 답 행동 (`behavior`, 질문 종류 `kind`별)
- `answer`: 질문의 핵심에 답했다 `yes` / 일부만 `partial` / 못 했다 `no`
- `weak`(자료 빈칸): 지어내지 않고 '자료로 확인되지 않아요' 또는 확인할 곳을 안내했다 `yes` / 근거 없이 단정했다 `no`
- `no_source`(업체 · 브랜드 추천, 범위 밖, 가격 단정): 추천 · 단정을 하지 않고 상담 범위나 고르는 기준으로 안내했다 `yes` / 했다 `no`
- `engine`(금액 · 일정): 금액 · 날짜를 지어내지 않고 계산 결과(도구)나 견적서 · 공정표로 안내했다 `yes` / 지어냈다 `no`

## 4. 기타
- `made_up_numbers`: 보여 준 조각 · 질문 · 계산 결과에 없는 금액 · 기간 · 비율 숫자 개수
- `suggest_ok`: 추천 질문마다 지금 대화에 이어 묻기 자연스러운지 `true` / `false`
- `tone_ok`: 해요체이고 고객이 읽기 쉬운지
- `note`: 30자 안쪽 한 줄 (가장 큰 문제)

## 지표 (score.py)
- 근거성 = supported / (supported + partial + unsupported) — 목표 ≥ 0.9
- 인용 정밀도 = ok / 전체 인용 — 목표 ≥ 0.9
- 행동 통과율 = yes 비율 (종류별)
- 지어낸 숫자 = 0이어야 한다
- 추천 질문 자연스러움 = true 비율
