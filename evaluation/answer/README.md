# 답 품질 평가

상담 답(`/v2/ask`)이 근거대로 말하는지, 해서는 안 되는 말을 하지 않는지 잰다. **유료**(답 쓰기만, 판정은 Claude 서브에이전트라 OpenAI 비용 없음).

## 파일
- `set30.jsonl`: 30문항 (dev 20 · held-out 10). 자료로 답함 18(새 300세트 15 · 90세트 3) · 자료 빈칸 3 · 답하면 안 됨 6 · 계산 엔진 3. 고객 집 정보(32평 · 도배 · 목공 · 기본형)를 넣고 묻는다
- `run.py`: 실제 상담 흐름(`ask.start`)으로 답하게 하고 토큰 · 비용을 남긴다. 누적 `--cap` 달러를 넘으면 멈춘다. 입구 관문의 Jev(별도 유료)는 끈다
- `judge.md`: 판정 기준 (문장 근거성 · 인용 · 질문 종류별 행동 · 지어낸 숫자 · 추천 질문 · 말투)
- `score.py`: 판정(`.cache/judged_*.json`) + 실행 기록으로 지표

## 돌리기
```bash
cd backend && uv run python ../evaluation/answer/run.py --cap 2.0   # LLM_LIVE=true, DATABASE_URL=지식 자료가 활성인 DB
python evaluation/answer/score.py            # dev만, --final이면 held-out까지
```

## 드러난 문제 (고칠 순서)
1. **추천 질문** (코드, 무료로 다시 잴 수 있음)
   - 다음 단계 고정 질문("도배 끝나고 바닥은 언제 깔아요?")이 맥락 없이 붙고, 바닥은 범위 밖이다
   - 범위 밖 공정(창호 · 샷시 · 욕실 · 타일 · 조명) 질문, 브랜드 추천 질문이 거르기를 통과한다
   - 방금 질문과 뜻이 같은 질문이 글자 겹침 0.6 아래라 통과한다 (예: 폐기물 신고)
2. **근거성 0.72~0.75**: 사실 문장의 약 20%가 조각에 없는 단정 · 조건을 덧붙인 '일부 근거'다. 보여 준 조각에 더 맞는 근거가 있는데 쓰지 않은 경우도 있다
3. **범위 밖 · 믿집 흐름 안내**: 욕실 덧방 · 바닥재 질문에 범위 밖이라 말하지 않고 답한다. 일정이 밀리는 질문에 '업체 연기 → 고객 승인 → 공정표 재조정' 흐름 대신 고객이 직접 업체에 연락하라고 한다
4. **숫자 검사 뒤 끊긴 글**: 기간 문장이 빠지면 남은 문장의 '이 기준'이 가리킬 것이 없어진다 (xm079)
5. 자료 빈칸 질문에서 조각에 없는 내용을 단정한 경우 1건 (xc084, 내용증명)
