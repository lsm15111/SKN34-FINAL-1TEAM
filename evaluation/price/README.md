# 견적 범위 백테스트 (실견적 ↔ 계산 엔진)

실제 아파트 도배 · 목공 견적과 낸 금액을 모아, 같은 조건으로 계산 엔진을 돌려 표준견적서 · 예상 범위가 맞는지 본다.
가정값(`refprice/market.py` · `refprice/spaces.py`)을 고칠 때마다 다시 돌려 숫자로 확인한다. 자세한 분석은 `docs/research/T10_real_quote_backtest.md`(docs-agent-design 브랜치).

## 돌리기

```bash
cd backend
uv run python ../evaluation/price/backtest.py --fit          # 요약 + 보정 힌트(지금 가정값)
uv run python ../evaluation/price/backtest.py --csv 결과.csv  # 건별 결과(엔진 범위 · PIT · 수량 비)
uv run python ../evaluation/price/backtest.py --split heldout # 확인용 1/3만
uv run python ../evaluation/price/backtest.py --rules 2026H2-r2 --split heldout  # 예전 가정값과 견주기
```

- `--ext`: 확장 여부를 모르면 확장으로, `--vat`: 부가세 여부를 모르면 포함으로 본다(민감도 확인).
- `--rules`: 범위 가정값 버전(기본은 지금 쓰는 값), `--since 2025`: 그해 이후 자료만.
- 가정값은 `dev`(id 해시 2/3)로만 맞추고 `heldout`(1/3)으로 확인한다. 같은 자료로 맞추고 확인하지 않는다.
- DB가 필요 없다. 계산 엔진(`app.calc`)만 쓴다.

## 결과 (2026-11-08, 지금 기본값 2026H2-r4)

모든 가정값은 이 자료의 dev로 고쳤다. 표준견적서 금액은 그대로이고 예상 범위만 바뀐다.

- r3: 합지 시장 중심 0.65 → 0.47, 업체 단가 σ 실크 0.17 → 0.21 · 합지 0.25 → 0.15 · 목공 0.24 → 0.30, 최소 금액 도배 25만 → 20만 · 목공 40만 → 25만 · 방문만 30만 → 20만(시장 하한), 목공 천장 철거는 공사 크기만큼 줄임(최소 20%).
- r4: r3 + **일부 공간 도배를 업체 견적 구조로**. 가운데 = 벽지 롤 수 × 롤 단가(실크 4.5만 · 합지 2.1만) + 도배사 품 × 일당 25만 + 부자재 max(3만, 롤당 1만).
  - 롤은 벽 · 천장을 따로 세어 올린다.
  - 품은 롤 수 ÷ 하루 롤 수(실크 3.3 · 합지 6.5)를 하루 단위로 올리고, 거실 천장이 들면 최소 2품이다.
  - 철거 · 폐기물은 이 금액에 든 것으로 본다.
  - 값은 영진벽지 견적 내역 dev로 잡았고, heldout도 같은 값이었다.

- 구간 점수: (범위 폭 + 범위 밖으로 벗어난 만큼 × 10) ÷ 실견적의 평균. 좁기만 한 범위와 넓기만 한 범위를 함께 벌한다.
- 수량: 견적의 롤 수 · 시공평을 면적으로 바꾸면 엔진 면적과 같다(중앙값 1.00, P10 0.89 · P90 1.25, 280건).
- 가견적 흉내: 영진벽지의 실제 단가(롤 · 품 · 부자재)에 엔진 수량을 곱하면 실제 견적의 중앙값 1.01배, ±10% 안 72% · ±20% 안 87%(268건).
- 실크는 연도가 내려갈수록 가운데보다 싸다(2024년 0.81 → 2026년 1.02). 엔진은 2026 하반기 기준이라 2025년 이후 자료를 우선한다.
- 합지는 r2가 해마다 약 30% 높게 잡았다. 시장은 합지 인건비를 실크의 절반쯤 받는다(10평당 실크 약 1.7품, 합지 약 0.9품).
- 방 1칸: r3까지는 집 전체 단가를 몫만큼 깎고 고정비 · 철거를 더해 실견적보다 높았다. 업체는 방 하나를 1품 + 롤 3개 + 부자재로 받는다(작은방 합지 = 3롤 × 2.1만 + 25만 + 4만 = 35.3만).
- 방 여러 칸은 dev 15건에서 범위 안 60% → 47%로 낮아졌다(heldout 11건은 82% 그대로, 전체 구간 점수는 1.35 → 1.26으로 나아짐). 견적의 롤 수가 엔진 면적보다 약 25% 많고(일부 공간 영진벽지 19건), 디아망 같은 고급 실크가 섞여서다. 일부 공간 로스를 1.25로 키우면 dev는 나아지지만 heldout이 나빠져 그대로 뒀다.
- 아직 안 맞는 것: 방 여러 칸(위), 작은 목공(일부 공간 12건 범위 안 58%). 합지 공정표 기간 · 천장 비중 · 고급형 등급 · 지역 보정은 표준견적서가 바뀌어 팀이 정한다(T10 4절).
