# 견적 범위 백테스트 (실견적 ↔ 계산 엔진)

실제 아파트 도배 · 목공 견적과 낸 금액을 모아, 같은 조건으로 계산 엔진을 돌려 표준견적서 · 예상 범위가 맞는지 본다.
가정값(`refprice/market.py` · `refprice/spaces.py`)을 고칠 때마다 다시 돌려 숫자로 확인한다. 자세한 분석은 `docs/research/T10_real_quote_backtest.md`(docs-agent-design 브랜치).

## 돌리기

```bash
cd backend
uv run python ../evaluation/price/backtest.py --fit          # 요약 + 보정 힌트
uv run python ../evaluation/price/backtest.py --csv 결과.csv  # 건별 결과(엔진 범위 · PIT · 수량 비)
uv run python ../evaluation/price/backtest.py --split heldout # 확인용 1/3만
```

- `--ext`: 확장 여부를 모르면 확장으로, `--vat`: 부가세 여부를 모르면 포함으로 본다(민감도 확인).
- 가정값은 `dev`(id 해시 2/3)로만 맞추고 `heldout`(1/3)으로 확인한다. 같은 자료로 맞추고 확인하지 않는다.
- DB가 필요 없다. 계산 엔진(`app.calc`)만 쓴다.
