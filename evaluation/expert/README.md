# 전문가 답 평가

라우터가 공정 전문가에게 넘긴 질문에 공정 에이전트(`spec.agent.answer`)가 그 공정 지식만으로 짧고 쉽게 답하는지 본다.
입력은 상담과 같다: 카드로 만든 집 정보 글(`consult.service.facts`, 그 공정 칸 + 공통 칸) + 질문 한 문장.

## 사례 (4,800개 · 범주 = 공정.주제, 10공정 × 주제 10개 = 100개 × 48: dev 32 · held-out 16)

| 주제 | 질문 예 | 핵심 말 (답에 있어야 함) |
| --- | --- | --- |
| compare 종류 비교 | 합지랑 실크 차이가 뭐예요? | 두 쪽 모두 |
| choose 고르기 | 벽지는 뭘로 하는 게 좋아요? | 선택지 하나 이상 |
| visit 실측 | 실측 때 뭘 확인해요? | 실측 · 확인 |
| cost 비용 | 도배 비용이 얼마나 나와요? | 표준견적서 · 화면 · 실측 · 업체 (숫자 없이) |
| duration 기간 | 도배 하루면 끝나요? | 공정표 · 화면 · 실측 · 업체 (숫자 없이) |
| caution 주의점 | 견적 받을 때 뭘 조심해요? | 확인 · 미리 · 받아 두기 |
| order 순서 | 목공이랑 도배 중에 뭐 먼저 해요? | 먼저 · 뒤에 · 순서 |
| living 살면서 공사 | 살면서 도배해도 돼요? | 짐 · 가구 · 덮기 |
| scope 이 공정 밖의 일 | 누수 원인도 봐 주나요? | 따로 하는 공사 |
| term 업계 말 | 견적서에 덧방이라고 있는데 무슨 뜻이에요? | 그 말의 쉬운 풀이 |

- 손으로 쓴 질문(`phrases.BANK`)과 스펙 · 지식에서 뽑은 말을 넣은 질문(`GENERIC`)을 같이 쓴다. 10공정 모두
  종류 비교 2~4거리 · 고르기 1~2거리(질문 9개 · 핵심 말 · 모범 답)와 실측 · 비용 · 기간 · 주의점 · 순서 · 살면서 공사
  질문 9개씩을 손으로 썼다 (도배 · 목공 밖 공정은 지식의 종류 · 고르는 것 · 실측 · 주의사항에서). 이 공정 밖의 일은
  지식 '쓰는 법'의 범위 밖 목록, 업계 말은 `scorers/terms.py` 용어 중 그 공정 지식에 나오는 것이다.
  손으로 쓴 질문이 없는 새 공정은 `GENERIC`만으로 만든다 (스펙 선택지가 '…요'로 끝나면 비교 질문은 만들지 않는다).
- 범주 안에서 무엇을 묻는지는 고르게, 카드 상태 · 카드에 그 공정이 있는지 · 집 이야기 앞말('살면서 하는데') · 잡음은 값마다 고르게.
- 질문 조각은 묶음마다 3개 중 1개가 held-out 전용이다. 같은 입력은 넣지 않고, 질문 + 집 정보가 근사 중복이면 다시 뽑는다.

## 채점 (`score.py`, 코드 · 모델 원문 기준)

| 검사 | 기준 |
| --- | --- |
| `answer_ok` | 답이 있고 300자 이하 (`check_answer`와 같음) |
| `no_number` | 금액 · 기간 · 면적 숫자(`NUMBER_CLAIM`)와 '하루면 끝나요' 같은 말이 없음 |
| `sources_known` | 출처 id가 그 공정 지식 목록 안 |
| `style` · `short` · `no_ask` | '-해요'체, 4문장 이하, 되묻지 않음 |
| `terms` | 업계 말은 처음 나온 문장에서 풀어 씀 |
| `on_topic` | 위 표의 핵심 말이 있음 |

판정 LLM(`--judge N`, 역할 judge)은 `judge/rubric_expert_v1.md`로 질문에 맞게 답함 · 필요한 정보만 · 쉬운 말 · 틀린 내용 없음을 1~5점 매긴다.

## 실행 (저장소 루트에서)

```bash
cd backend
uv run python ../evaluation/expert/make_cases.py                       # 사례 만들기 (약 25초)
uv run python ../evaluation/check_cases.py --only expert               # 무료 점검 (T0)
uv run python ../evaluation/expert/run.py --sample 20 --judge 10        # 호출 수 · 예상 비용만
uv run python ../evaluation/expert/run.py --sample 20 --judge 10 --fake # 가짜 LLM, 무료
uv run python ../evaluation/expert/run.py --trade dobae --sample 20 --live  # 실제 호출 (유료, 승인 뒤)
```
