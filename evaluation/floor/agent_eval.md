# 바닥 에이전트 평가

바닥 60문항(`questions.jsonl`)을 LLM 끔 · LLM 켬으로 같은 턴 흐름(`turn.run_turn`)에 넣어 견줘요. 스크립트는 `agent_eval.py`예요.

## 재는 것

- 근거 맞는 답: 보여 준 글 + 인용한 조각 원문에 문항 근거 낱말 규칙이 다 들어 있음(`coverage.py`와 같은 판정)
- 모름 · 되묻기 · 끝난 까닭(ok · ask · llm_error · bad_format · all_dropped · over_budget)
- LLM 호출 수 · 도구 · 검사에서 빠지거나 바뀐 문장 · 토큰 · 비용 · 시간
- 바닥 판단 루프만 재요. 다른 담당의 LLM 다시 쓰기는 막아서 그 문항은 LLM 끔 답 그대로예요.

## LLM 켬(2026-11-26, 사용자 승인 · 상한 $4)

| 근거 맞는 답 | 14/60 | 44/60 |
| 모름 | 42/60 | 11/60 |
| 되묻기 | 1/60 | 1/60 |

- 모델 `gpt-6.1-terra`(추론 low) · 지시문 `trade_agent_v1`

- 루프 안에서 근거 맞음 38/41. 아닌 3개: f10(PE폼 까는 이유가 dev 자료에 없음, W8 원문 몫) · f34(AS 기간) · f43(답은 맞지만 '참고 기준' 낱말 규칙에 안 걸림)
- 도구: 검색만 19 · 두 개 11 · 세 개 6 · 네 개 5. LLM 호출 97번(문항당 1.6)
- 토큰: 입력 216,424(캐시 129,241) · 출력 7,930. 비용 $0.1333, 문항당 평균 5.8초 · 최대 18.1초
- 검사에서 빠지거나 바뀐 문장 5개(근거와 안 맞는 문장 4 · 범위 밖 말 바꿈 1)
- 답을 읽어 보니(14문항) 고칠 것:
  - f07: 금 간 바닥 질문에 '난방 배관 · 보일러 공사는 바닥 업체 몫이 아니에요'가 붙음. 고객이 묻지 않았는데 범위 밖 정해 둔 글이 들어감
  - 정해 둔 글(금액 · 기간 안내) 묶음과 에이전트 묶음에 '[바닥]' 제목이 두 번 나옴
  - f34: AS 기간 질문에 금액 · 기간 정해 둔 글이 붙음(관문 FLAGS, 4.9)
  - f44: 실내공기질 관리법 적용 대상을 세대 공사에도 의무처럼 읽힐 수 있게 씀
- 판정은 근거 낱말 규칙이라 사람 확인이 더 필요해요(결과 JSON은 저장소 밖 `d10-/data/rag-floor/results/agent_live_20261126.json`)

## LLM 켬 비용 어림

- 모델 `gpt-6.1-terra`(추론 low), 가격은 `evaluation/answer/run.py`와 같아요(100만 토큰당 입력 $1 · 캐시 입력 $0.05 · 출력 $5).
- 토큰은 글 1자를 1토큰으로 넉넉히 잡았어요.
- 보통: 루프 41문항 × 호출 3번(검색 두 번 + 답) × 입력 약 6천 토큰 + 출력 약 1천5백 토큰 → 약 $1
- 최대: 41문항 × 호출 6번 × 입력 약 1만2천 토큰 + 출력 → 약 $3.6
- `--cap` 기본 4달러를 넘으면 그 뒤 호출을 막고 멈춰요.

## 돌리기

```bash
cd backend
uv sync --locked
# LLM 호출 없음
.venv/Scripts/python.exe -I -X utf8 ../evaluation/floor/agent_eval.py --dry --out <저장소 밖 결과.json>
# LLM 켬(승인 뒤, LLM_LIVE=true · 키 필요)
.venv/Scripts/python.exe -I -X utf8 ../evaluation/floor/agent_eval.py --cap 4 --out <저장소 밖 결과.json>
```
