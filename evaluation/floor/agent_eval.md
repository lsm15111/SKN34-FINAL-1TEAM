# 바닥 에이전트 평가

바닥 60문항(`questions.jsonl`)을 LLM 끔 · LLM 켬으로 같은 턴 흐름(`turn.run_turn`)에 넣어 견줘요. 스크립트는 `agent_eval.py`예요.

## 재는 것

- 근거 맞는 답: 보여 준 글 + 인용한 조각 원문에 문항 근거 낱말 규칙이 다 들어 있음(`coverage.py`와 같은 판정)
- 모름 · 되묻기 · 끝난 까닭(ok · ask · llm_error · bad_format · all_dropped · over_budget)
- LLM 호출 수 · 도구 · 검사에서 빠지거나 바뀐 문장 · 토큰 · 비용 · 시간
- 바닥 판단 루프만 재요. 다른 담당의 LLM 다시 쓰기는 막아서 그 문항은 LLM 끔 답 그대로예요.

## LLM 호출 없음(가짜 응답, 2026-11-26)

가짜 응답(검색 한 번 → 첫 근거 글 낱말로 답)으로 흐름 · 검사 · 글 크기만 쟀어요. 답 품질 평가가 아니에요.

| | LLM 끔 | 가짜 응답 |
| --- | --- | --- |
| 근거 맞는 답 | 14/60 | 17/60 |
| 모름 | 42/60 | 12/60 |
| 되묻기 | 1/60 | 1/60 |

- 루프를 탄 문항 41개(ok 38 · 검사에서 다 빠짐 3), 안 탄 문항 19개
  - 안내(guide) 8 · 다른 공종이 먼저 잡힘 8(설비 · 욕실 · 타일 · 창호 · 목공 · 공종 없음) · 여러 공종 2 · 범위 밖 1('강아지')
  - 관문 몫이라 W10에서 고쳐요
- 호출 입력 글 크기: 평균 3,838자 · 최대 6,152자(지시문 + 도구 정의 + 질문 + 근거 글 8개)

## LLM 켬 비용 어림

- 모델 `gpt-6.1-terra`(추론 low), 가격은 `evaluation/answer/run.py`와 같아요(100만 토큰당 입력 $1 · 캐시 입력 $0.05 · 출력 $5).
- 토큰은 글 1자를 1토큰으로 넉넉히 잡았어요.
- 보통: 루프 41문항 × 호출 3번(검색 두 번 + 답) × 입력 약 6천 토큰 + 출력 약 1천5백 토큰 → 약 $1
- 최대: 41문항 × 호출 6번 × 입력 약 1만2천 토큰 + 출력 → 약 $3.6
- `--cap` 기본 4달러를 넘으면 그 뒤 호출을 막고 멈춰요.

## 돌리기

```bash
cd backend
uv sync --locked
# LLM 호출 없음
.venv/Scripts/python.exe -I -X utf8 ../evaluation/floor/agent_eval.py --dry --out <저장소 밖 결과.json>
# LLM 켬(승인 뒤, LLM_LIVE=true · 키 필요)
.venv/Scripts/python.exe -I -X utf8 ../evaluation/floor/agent_eval.py --cap 4 --out <저장소 밖 결과.json>
```
